## 1. 这条流水线整体上能否由现有算子库与运行时表达

**结论：partial。** 训练期的“裁聚合模型 + 加各向同性高斯噪声”在 catalog 里有逐字对应的算子；测试期的“采样—投票”可以用循环加几行张量运算拼出来，“Hoeffding 界 / 弃权判定”是标量算术；但**认证半径这一步既拿不到标定数据，几何也对不上**，而且整条方法里裁剪、加噪、证书全都定义在完整参数向量 $w\in\mathbb{R}^d$ 的 $\ell_2$ 球上，运行时手里只有 LoRA 因子状态。

| 步 | 归类 | 依据 |
|---|---|---|
| 1 下发（含噪）全局模型 | outside | 常规下发骨架；动作层是 `outgoing` 的 `transform_broadcast`，但本步不改内容（噪声在第 6 步已加） |
| 2 客户端 mini-batch SGD | outside | 普通本地训练，运行时只把它当黑盒（`trace/scalars/step`、`gradients/batch_gradient/parameter` 等坐标） |
| 3 计算上传增量 | op | `states.delta(state, base)` 逐项做差，语义完全一致；服务器侧另有坐标 `uploads/factor_delta/client` |
| 4 加权聚合 | outside | 标准 FedAvg；算子层 `states.weighted_average`（文档即写 “FedAvg in factor space”）+ `states.add` |
| 5 裁聚合模型的 ℓ2 范数 | op | `update.clip_state_norm(state, bound)` = 缩放整个 state（**不是**增量）到范数 ≤ bound，返回 factor ≤ 1，与 $w/\max(1,\lVert w\rVert/\rho)$ 一致；`update.clip_to_norm` 只管增量，不适用 |
| 6 加各向同性高斯噪声 | op | `update.add_gaussian_noise(state, sigma, generator)` 逐项独立 $N(0,\sigma^2)$，$\sigma_t=0.01$ 是绝对标准差，正好不用按敏感度缩放；`update.clip_and_noise` 是裁批梯度的另一套机制，不要混用 |
| 7 末轮只裁不加噪 | op | 同第 5 步，换个 $\rho_T$ |
| 8 生成 M=1000 个噪声模型 | op | 循环调用 `update.add_gaussian_noise`，用 `model.lora(state)` 逐个装载；缺的只是“一次评估 M 个扰动副本”的推理原语（成本问题，不是表达问题） |
| 9 逐样本投票计数 | compose | 循环前向 + `argmax`/`bincount`/`topk`，catalog 无投票算子但几行可拼 |
| 10 Hoeffding 上下界 | compose | `log`/`sqrt` 两行标量运算 |
| 11 接受/弃权 | compose | 一次 `p_A > p_B` 比较与分支 |
| 12 认证半径 RAD | needs_runtime | 公式本身可 compose（$\Phi$ 用 `erf`），但输入不在地上 |

三处结构性障碍：

1. **参数空间不一致（几何）**。CRFL 裁/扰动的是完整参数向量 $w\in\mathbb{R}^d$，证书是 $\lVert\cdot\rVert_2$ 球；`update.clip_state_norm`/`update.add_gaussian_noise` 作用在 LoRA 因子 $(B,A)$ 上。因子空间的球 ≠ 乘积空间 $\Delta W=BA$ 的球，也不等于“基座 + 低秩和”的整模型范数球。词表给了 `uploads/product_delta/client` 和 `lowrank.gram`（可免展开算 $\langle \Delta W_i,\Delta W_j\rangle$，于是 $\lVert\sum p_i\Delta W_i\rVert_F=\sqrt{p^\top G p}$ 能 compose 出来），但 **“冻结基座 + 低秩和”的范数**没有现成算子。
2. **动作层缺口**。`aggregate` 的 `modified_by` 只有 `replace_global`/`select_and_weight`，词表里没有“裁剪/扰动聚合结果”的动作；函数层（`update.*`）做得出来，词表层没词，最接近的是把扰动记在“下发内容”上（`outgoing` 的 `transform_broadcast`）。这不阻塞表达，但会阻塞按制品/动作记账。
3. **认证所需数据与推理成本**。$\tau_i,\eta_i,q_{Bi}/n_{Bi},\gamma_i,\rho_t,\sigma_t,T,t_{adv}$ 没有任何 coordinate；且测试期要为**每个测试样本**装载 M=1000 个噪声模型逐个前向——`model.lora` 支持推理期换装（所以“推理时介入”本身不是阻塞），但没有批式平滑评估原语。

## 2. 缺的东西里哪些是通用的，哪些是这篇论文特有的

**通用（别的方法也会用到）**

- **“约束/净化聚合结果”的动作词**：DP-FedAvg、稳健聚合、聚合后加噪/缩放这一类后处理防御都需要改 `aggregate`，而词表只允许 `replace_global`/`select_and_weight`。函数（`update.clip_state_norm`、`add_gaussian_noise`、`scale_to_norm`）已经有了，缺的是动作与允许修改 `aggregate` 的声明。
- **逐客户端训练配置与梯度界坐标**（$\tau_i$ 本地步数、$\eta_i$ 学习率、$q_{Bi}/n_{Bi}$ 批采样比、$\gamma_i$ 局部梯度范数界）：任何把本地训练折进敏感度/证书账本的方法（DP-FedAvg 会计、认证鲁棒 FL、FLTrust 类归一化）都要。现只有 `trace/scalars/step`、`channel/self_reported/client`（自报值，不可信）。
- **一次评估 K 个扰动模型并汇总（投票/平均）的推理原语**：随机平滑、MC dropout、深度集成、TTA 通用；现在只能 Python 循环 `model.lora` + 前向。
- **正态 CDF/分位数（$\Phi,\Phi^{-1}$）与二项比例置信区间（Hoeffding / Clopper–Pearson）**：通用统计工具，catalog 没有；前者一行 `erf` 可拼，后者几行。若提升为算子应属 `robust_statistics`。
- **低秩和的乘积空间范数**（$\lVert\text{base}+\sum p_iB_iA_i\rVert$ 或 $\lVert\sum p_iB_iA_i\rVert_F$ 的免展开计算）：LoRA FL 里任何按“有效更新范数”裁剪/度量/加噪的方法都要；`lowrank.gram` 只能对一张同形状低秩表两两内积，处理不了带冻结基座的和。

**这篇论文特有**

- RAD 闭式公式及其常数：$L_Z=\sqrt{2+2\rho+\rho^2}$、$R=1$、逐轮复合项 $\prod_t(2\Phi(\rho_t/\sigma_t)-1)$、敏感度项 $\sum_i(p_i\gamma_i\tau_i\eta_i q_{Bi}/n_{Bi})^2$、$\gamma_i$ 取值（10/20）、$\rho_t$ 线性调度（0.025t+2 / 0.1t+2 / 0.25t+4）、$\sigma=0.01$、$M=1000$、$\alpha=0.001$。
- “裁聚合后的全局模型而不是裁各客户端增量”“最后一轮只裁不加噪”这两个具体机制选择。
- 用 Hoeffding 校正后的 top-2 边际做接受/弃权（$p_A>p_B$）的判定式，以及原文 $2N$ 与 Monte Carlo 次数 $M$ 的笔误。
