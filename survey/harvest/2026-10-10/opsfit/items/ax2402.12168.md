# 1. 这条流水线整体上能否由现有算子库与运行时表达

**结论：只能是 partial（部分可表达）。** 有意思的是，这条流水线里**没有一步需要 catalog 里的新算子**——catalog 的 clustering / density / robust_statistics / spectral_decomposition / lowrank 这一大批函数在这条流水线里一个都用不上，因为 PSIM 是"样本级、训练后、单模型"的检测，不是聚合侧的统计防御。它真正触及的是运行时的**动作面**（改样本、剔除样本）和**取数面**（模型句柄前向）。

逐个环节核对：

- **步骤 1（重置标签）**：词表里 `samples` 的 `modified_by` 含 `mask_samples` / `edit_samples`，把 `(x, y)` 改成 `(x, y_r)` 就是样本级改写 → 对应 `edit_samples`。注意词表**没有单独的"逐样本标签" coordinate**（只有 `samples/manifest/sample`、`samples/text/sample`），标签只在本地训练回路里被隐式消费，这算一个轻微的口径缺口，但不至于让这步做不了。
- **步骤 2（PEFT 继续训练 PSIM）**：从"训练一个独立模型"这层看它像普通本地训练；但运行时是**纯 LoRA 因子**的：状态坐标全是 `received/factors/module`、`trace/factors/step`、`local_update/factors/module`、`uploads/factor_delta|product_delta`，句柄只有 `model.lora(state)`。论文主实验用的是 **P-tuning v1 软提示**（full-tuning / Prompt-tuning / P-tuning v2 也在消融里），这些参数在运行时既挂不上也训不了，只有 Table 3 的 LoRA 消融这一档能落地。此外 `θ_p`（待检测的中毒 PEFT 权重）在词表里没有专门取法，只能借 `received/factors/module` 或 `local_update/factors/module` 近似。→ 归 `needs_runtime`。
- **步骤 3（PSIM 置信度）**：这是取数。运行时能给的是 `samples/loss/sample`（`model.losses`）和 `samples/text_logprob/word`（`model.logprob`），都是模型句柄直接提供的前向结果 → `runtime_data`。**疑点**：论文自己都"未说明" C 的定义（只说二分类下 clean≈50%、poisoned 更高），而运行时没有"逐样本类别概率"这个 coordinate；若 C 就是最大 softmax 概率，只能用 `model.activations(samples, select)` 取到分类头输出后再做一次 softmax/exp（几行张量运算，compose 级），或退一步用 `exp(-loss)` 当单调代理。另一个 catalog 级替代是 `samples/hidden_state/sample` + `probe.fit_logistic`/`probe.apply_logistic` 给出一个校准过的逐样本概率，但那就不是 PSIM 自己的输出了。
- **步骤 4（阈值判定与过滤）**：`C > γ` 只是一次比较 + 取索引，属于"普通张量运算"，不需要新算子（也**不要**硬套 `robust.quantile_threshold`——它要 benign 参考样本和 FPR；也不要套 `density.kde_valley_threshold`——它要密度双峰山谷，二者都不是固定单点门限）。真正对应词表动作的是：poisoned 样本剔除 → `mask_samples`；clean 样本 `y ← Victim Model(x)` → 又一次样本改写 → `edit_samples`（需要 `model.generate`/`model.logprob` 之类前向）。γ ∈ [0.6, 0.8] 只是普通超参。

所以"改标签 → 本地再训练 → 前向取分 → 门限过滤"这条链在**制品/动作层面是闭合的**（`edit_samples` + 取前向分数 + `mask_samples`），不是 no；但**主实验的 PEFT 形式**和**置信度口径**两处对不上，所以是 partial。

# 2. 缺的东西里哪些是通用的，哪些是这篇论文特有的

**通用缺口（别的方法也会用到，值得补进库）**

1. **非 LoRA PEFT 的挂载与训练入口**（软提示 / prompt tuning / adapter，以及"影子模型/第二套适配器与主模型共存"）。任何走 P-tuning、prompt、adapter，或需要训练影子/辅助模型的 PEFT 攻防方法都会撞上同一堵墙；运行时目前只有 `model.lora(state)` 和因子表示。
2. **逐样本类别概率 / 校准置信度 coordinate**（类似 `samples/probability/sample`）。样本级检测、误分类识别、成员推断、噪声标签学习都要它；现在只有 `samples/loss/sample` 和 `samples/text_logprob/word`。
3. **可读可写的逐样本标签 coordinate**。重打标、样本清洗、噪声标签学习通用；现在标签只在训练回路里隐含存在。
4. **"以任意检查点初始化、在客户端跑一次不参与联邦轮次的独立微调"的训练入口**。凡是后训练/离线阶段的检测器、探针、影子模型训练都用得到。

**这篇论文特有的（不该做成通用算子）**

1. **"随机重置标签再训练、再看模型对原样本的置信度"这套 PSIM 配方本身**——reset 分布、reset 比例论文都没给，是这篇的检测配方而不是可复用计算单元；好在它用 `edit_samples` + 普通本地训练就能拼出来，所以**不构成 missing_op**（本流水线 missing_op 为空）。
2. **γ = 0.7 / 0.75、二分类下 clean≈50% 的经验口径**：论文特有参数，不是缺件。
3. **"检测器必须是中毒权重的副本 + 干净集重打标"这一设定**（而不是通用影子模型/参考数据方法）：论文特有；词表里最接近的信任假设是 `reference_data`（防御方持有可信参考数据），但这里的"干净集"是客户端自己的 `samples`，语义并不完全相同。
