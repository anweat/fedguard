## 1. 这条流水线整体上能否由现有算子库与运行时表达

**结论：不能（expressible = no）。** 缺口不在某个公式，而在运行时完全没有触及"训练回路内部"。

这条流水线的防御力只来自两件事：

1. **结构上**：冻结可能被投毒的基座 PLM，插入随机初始化的 PEFT 层（adapter / LoRA / prefix），保证只有"干净的新参数"会被训练；
2. **目标函数上**：在本地训练损失里加两项 —— Lamp = −Σ_i Σ_p ‖W_p‖₂（PEFT 权重范数取负求和）与 Lreg = Σ_i Σ_h ‖a_h‖₂（逐层逐头注意力分数范数求和），L = Ltask + λamp·Lamp + λreg·Lreg，然后常规反传，再用干净验证集标定 λ。

对照三份材料：

- **catalog 是一个"更新空间"的算子库。** 全部函数处理的都是已经算出来的张量/状态：距离矩阵、Gram、低秩因子、聚类标签、稳健统计量、标量序列、DCT/PCA 变换。没有任何一个函数进入训练图 —— 没有损失项构造，没有模块权重范数惩罚，没有注意力读取或正则，没有超参搜索或准确率评估。最接近的 states.norm / states.flatten 也只能对**训练结束后**的 State 快照取范数，拿不到 requires_grad 的步内权重。
- **vocabulary 把可改的东西限死了。** 制品只有 samples / received / gradients / trace / local_update / uploads / aggregate / outgoing / channel / history；动作只有 mask_samples、edit_samples、transform_received、transform_gradients、transform_update、select_and_weight、replace_global、transform_broadcast。**"损失"不是制品**，也没有"改模型结构/改可训练参数集合"这个维度，因此整条防御链在词表里无处落脚（既不是取某个 coordinate，也不是执行某个 action）。
- **模型句柄是只读的口子。** model.losses / hidden / activations / per_sample_gradients / logprob / generate 只能给逐样本读数，没有"把可导项塞回前向-反向图"的入口，也没有下游分类准确率（CACC）的评估方法；model.lora(state) 只能临时载入一个已存在的 LoRA 状态，不能新建模块、随机初始化或指定冻结集合。

所以 7 步里**没有一步落在 op / runtime_data / runtime_action / compose / missing_op**：第 2、4 步的算术本身确实只是几行乘加与求范数（compose 级），第 3 步的注意力张量勉强沾 samples/activation/sample 的边，但它们共同的、决定性的缺口是"**步内可导 + 能进损失**"，按定义归 needs_runtime；第 5、7 步是标准本地训练与标准推理，归 outside，而它们本来就不是防御计算。运行时唯一能直接承接的部分，恰恰是这篇方法里不构成防御的部分。

## 2. 缺的东西里哪些是通用的，哪些是这篇论文特有的

**通用（换任何"训练期改目标/改结构"的防御都会撞上同一堵墙）：**

1. **损失注入接口**：训练步能接受外部损失项（或额外正则项）并一起反传 —— 所有改损失函数的防御（训练期正则、对齐约束、鲁棒训练、PEFT 防御）都要。
2. **步内可导的权重与激活读取**：能拿到"当前"PEFT 权重和逐层逐头注意力张量，且它们连在计算图上（而不是训练后的快照）。
3. **参数组冻结与模块注入**：只训练指定模块、新建并随机初始化 PEFT 模块（adapter / LoRA / prefix），并可切换三种变体。
4. **干净带标签验证集 + 下游准确率评估 + 超参网格搜索**：标定 λ、阈值、早停等都会用到。

这四条都是**框架能力**（needs_runtime），不是"某个可复用的张量计算单元"的缺失，所以这条流水线**不需要新增 missing_op**：范数求和、加权组合都是几行普通算术，真正买不到的是它们进入损失的通道。

**这篇论文特有的：**

1. **两个正则项的具体形状与符号**：范数取负当"放大器"（−Σ‖W_p‖₂）、只对 [CLS] 对应位置的注意力分数求范数再对头求和，以及"全 transformer 层 × 全 PEFT 模块 / 全层 × 全头"这一 scope。
2. **λ 的候选网格**（{0.001, 0.002, 0.003, 0.005} × {0.01, 0.02, 0.03, 0.05}）与"验证集 CACC 下降不超过 2% 取最大"的判据，以及论文未给出的最终取值。
3. **防御假设与组合方式本身**：认定 task-agnostic 后门藏在 PLM 预训练权重里，因此"冻结 PLM + 只训随机初始化的 PEFT + 把 PEFT 权重范数往大推"就能让后门无法被强化 —— 这个动机与组合是论文的。
4. **实验配置**：adapter reduction 16、LoRA rq = rv = 16 / alpha 16、prefix length 30 / bottleneck 256，以及各变体的学习率与 epoch 数。

一句话：通用的是"训练回路可编程性"，特有部分一旦有了这些能力就只是几行算术加超参。
