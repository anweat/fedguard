## 1. 这篇论文的攻击做了什么

论文攻击的是一条集中式（非联邦）LLM 微调流水线：Rapid Response 框架把在野捕获的越狱样本当作“参考”提交给一个增殖模型，由后者批量改写成合成变体，再用这些合成数据以 LoRA/QLoRA 微调 LlamaGuard 4 12B 越狱检测器。攻击者是向这条流水线提交参考的外部数据提供方，只能在小范围内篡改越狱参考的内容（不能改良性数据、不能改标签），且改后的参考必须仍被裁判模型判为“有害且与原查询同一行为”。核心手法是在一条真实越狱参考里嵌入 if-else 条件式提示注入：一旦上下文出现“proliferate”“derive prompt”等增殖线索词，IF 分支就丢弃原合成任务、逐字输出攻击者准备的少样本内容；防御者验证时走 ELSE 分支、照常执行原越狱，因此参考能通过两阶段验证。1% 参考投毒（18 条）经约 3.33 倍增殖放大成 54–72 条投毒训练样本（有效量还要乘注入成功率，故 1% 是上界）。攻击有两个目标：一是可用性退化，让检测器在带目标格式、领域、实体名或一般用户查询的良性输入上大量误报（1% 投毒下目标格式 FPR 90%–100%，实体名与领域约 78%–98%，一般分布在 5% 投毒时 39%–50%）；二是安全退化，即 Omission Attack，把“含概念 C 的良性查询删掉 C、并作为 unsafe 样本”注入训练集，使“概念 C 缺席”成为安全信号，推理时把 C 插进有害查询即可让越狱被判为安全（1% 投毒下 87%–98% FNR）。

## 2. 拆成哪几个威胁技术，为什么这样拆

按“目标 + 所需能力 + 改动的制品”拆，卡片里的攻击落成两条技术，区别在目标（让模型犯哪一类错），不在能力或制品。第一条 `shortcut_inducing_sample_injection`：把带目标表层特征的良性查询做成 unsafe 训练样本，诱导检测器学成“表层特征 = 不安全”的伪关联，目标是降低可用性（untargeted）。定向的格式/领域/实体名攻击与一般分布攻击只是载荷里选的特征不同（一般分布用贪心集合覆盖挑 3-gram），做法与能力完全相同，不拆开；附录里的直接投毒（绕过增殖）也只是同一载荷换了个投递通道，同样不单列。第二条 `concept_trigger_backdoor`：用“概念 C 缺席”的良性样本做 unsafe 样本，使 C 的出现反而预示“安全”，造成假阴性（backdoor + safety_removal）。

特意没有把“条件式提示注入”单列为第三条技术：它的目标、能力、制品与第一条完全相同，按本库“技术由目标、能力、制品定义”的口径那是同一条技术，注入只是第一条的投递与规避手段，写进 stealth_measures。两条技术也不互为变体：一条把“特征出现”关联到 unsafe，一条把“概念缺席”关联到 unsafe，方向相反、目标相反，不存在包含关系，因此 variant_of 留空。

## 3. 每个技术需要的能力与改动的制品

两条技术在词表里都只需要 `local_data`（控制某些客户端的本地数据，modifies: samples），另加 `defense_knowledge`：卡片明确说攻击者要知道“验证与增殖使用不同上下文”这一流水线不对称，否则写不出只在增殖时激活的条件分支。改动的制品都只有 `samples`。论文的入口是训练前的数据准备；损失函数与优化器设置、训练步数、更新缩放/投影、聚合与下发都不是攻击面（论文自己把这些优化配置列为防御方的训练配置），也没有客户端更新或服务器聚合可用。映射到联邦 LoRA 微调时：论文的攻击者是集中式流水线外部的数据提供方，最自然的对应是“控制部分客户端本地数据的恶意客户端”——投毒样本随本地训练进入本地 LoRA，再经聚合影响全局模型。论文赖以生效的两个前提在联邦里没有对应物：服务端可见的原始文本、以及把每条参考放大成约 3.33 条训练样本的 LLM 增殖步骤。因此第一条技术的投递方式（对增殖模型的提示注入）在联邦里完全对应不上，但它要投递的载荷（把良性查询当作 unsafe 样本）可以由控制本地数据的客户端直接实现，故条目仍记 `applicable: true`，把增殖环节当作论文特有前提说明；第二条技术的机理与联邦无关，理论上可由控制本地数据分布的客户端实现，但论文未验证，且依赖“概念在预训练语料中充分表示、可从良性样本干净移除、增殖后仍缺席”等条件，故记 `applicable: true` 并在 summary 中标注未验证。

## 4. 可能留痕的位置与依据

第一条技术：最直接的痕迹在样本文本层（`samples/text/sample`，reported）——投毒参考原文里能看到 if-else 注入块与“proliferate”“generate variations”等增殖线索词，论文的输入侧 guardrail 检测器正是在这个坐标上定位注入片段（干净参考 3.8% FPR、投毒参考 10.3% 聚合 FNR，SWE-bench 与 MCQ 模板仍漏检 24.1%/18.5%）；同一坐标的增殖产物上还能看到大量带目标表层特征的良性查询被打上 unsafe 标签、与 WildChat 安全分布重叠（reported，1% 投毒下目标格式 FPR 90%–100%，干净基线约 0%）。联邦映射下可推断：加载该客户端上传后用带目标特征的良性探针评测会出现异常假阳性（`uploads/probe_behavior/client`，inferred；卡片只有集中式最终模型上的行为数字，没有客户端级探针数据）。

第二条技术：训练样本文本里是“概念缺席”的良性查询被标为 unsafe，C 在安全数据里常见、在同类结构的投毒样本里完全不出现（`samples/text/sample`，reported）；机制证据在模型内部——加触发器的不安全提示的最后一 token 残差流激活在约第 30 层之后向安全区域偏移（`samples/hidden_state/sample`，reported，附录 F 图 20，需要白盒激活与一组干净的不安全/良性提示）。联邦映射下可推断：带/不带触发器的越狱探针在该客户端上传上的 FNR 差距会异常大（`uploads/probe_behavior/client`，inferred）。
