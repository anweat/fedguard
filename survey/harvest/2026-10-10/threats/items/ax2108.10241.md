## 1. 这篇论文的攻击做了什么

卡片描述的是一篇经典联邦学习（图像/表格数据，LeNet、VGG9 等；明确不涉及 LoRA 或 PEFT）的投毒攻击与关键评估论文。攻击者是被攻陷的客户端，目标是 untargeted poisoning——降低全体客户端在任意测试输入上的全局模型准确率，论文明确不研究定向与后门攻击。攻击有两个入口：本地数据准备阶段的标签翻转（SLF/DLF，offline，只改本地数据、不攻破设备），以及本地训练加更新上传前处理的模型投毒 PGA（online，白盒，把本地微调换成 SGA 造出恶意模型 θ′，再把 ∇′ = θ′ − θg 缩放或投影以绕过目标 AGR 的鲁棒性判据）。两者共用同一形式化目标：最大化投毒聚合与良性聚合之间的距离。论文用它们评估 Average、Norm-bounding、Multi-krum、Trimmed-mean，结论是在它主张的实际投毒比例（数据投毒 ≤ 0.1%、模型投毒 ≤ 0.01%）下这些聚合规则依然高度鲁棒。

## 2. 拆成哪几个威胁技术，为什么这样拆

拆成三个。第一，`label_flipping_data_poisoning`：静态与动态标签翻转只是"翻到哪个类"的规则不同，目标、所需能力、被改动的制品完全一致，因此合成一个技术。第二，`gradient_ascent_local_training`：PGA 里"造出恶意更新"的那一半，靠控制本地训练过程（SGD→SGA、反向梯度）把本地损失推高，得到方向相反的本地更新。第三，`update_scaling`：PGA 里"上传前投影"的那一半，对已经造好的更新做缩放、投影或 γ 搜索，使其能通过目标 AGR 的鲁棒性判据。

这样拆的理由是三者的能力与制品互不重叠（本地数据 / 本地训练过程 / 上传内容），而 `update_scaling` 是论文自己都强调"模块化、可替换任意 AGR"的通用规避手法，别的论文把它用在放大良性更新等场景时也会落在同一个名字下。SGA 与投影虽然在 PGA 中连用，但各自都能独立构成一类做法，所以不按论文的方法名合成一条。

## 3. 每个技术需要的能力与改动的制品

- `label_flipping_data_poisoning`：capabilities = `local_data`、`collusion`、`defense_knowledge`，modifies = `samples`。`local_data` 直接改本地样本；`collusion` 用于把多个被攻陷客户端的良性数据合并后统一翻转、把 |Dp| 做大；`defense_knowledge` 是因为 |Dp| 的取法按目标 AGR 定制（Average/Norm-bounding/Trimmed-mean 用大 |Dp|，Multi-krum 用小 |Dp|）。
- `gradient_ascent_local_training`：capabilities = `local_training`，modifies = `gradients`、`trace`、`local_update`，与词表中 `local_training` 的 modifies 一致。它不需要碰数据，也不需要知道 AGR。
- `update_scaling`：capabilities = `upload_content`、`defense_knowledge`，modifies = `local_update`、`uploads`。它要能改上传内容，并按 Kerckhoffs 假设知道 AGR 与 Norm-bounding 的阈值 τ；γ 搜索还要求在本地反复模拟目标 AGR。
- 迁移到联邦 LoRA 微调：三个技术都能落位——`samples` 对应本地样本/指令数据（标签翻转对应把标签或回答改成错误内容），`local_update` 与 `uploads` 对应客户端 LoRA 因子与相对下发的因子差。论文本身是联邦设定，所以三个技术 `federated` 均为 true、`applicable` 均为 true。需要提醒的是卡片明确指出论文完全没有涉及 LoRA/PEFT，多客户端采样带来的固有鲁棒性、M 的量级、以及逐维裁剪与范数阈值在低秩增量上的统计行为都超出论文范围。

## 4. 可能留痕的位置与依据

- 数据投毒：`samples/text/sample`（reported，论文明确给出翻到 C−1−y / C−y 或代理模型最不可能类的规则；同时明确服务器 nobox，只有能读本地数据的一方看得到）、`samples/loss/sample`（reported，Figure 2a 报告 |Dp| 越大投毒更新的损失越高）、`uploads/factor_delta/client`（reported，Figure 2b 报告范数随 |Dp| 增大，公式 (1) 要求方向偏离良性聚合）。
- SGA：`trace/scalars/step`（inferred，训练规则换成 SGA 后步内标量应随步上升；论文没有把训练标量当作可观测量报告）、`samples/loss/sample`（reported，论文说用 −∇θL(θ;b) 增大本地数据上的损失）、`local_update/aux_gradient/module`（inferred，上升方向得到的本地更新与良性样本梯度反号）、`local_update/factors/module`（reported，Algorithm 1 的 ∇′ = θ′ − θg）。
- 更新缩放：`uploads/factor_delta/client`（reported，论文明确把更新缩放到范数 τ、对 Average 乘任意大常数如 10²⁰）、`aggregate/result/model`（reported，攻击目标函数就是拉大 fagr 与 ∇b 的距离）、`aggregate/weights/client`（reported，Multi-krum 的 γ 搜索以被选入集合 S 的投毒更新数最多为目标）。
- 没有把握因此不写的坐标：`gradients/batch_gradient/parameter`（SGA 反向的是梯度的使用方向，论文未报告该坐标上的可观测差异）、`samples/manifest/sample`（翻标签不改哈希/来源/长度）、`history/features/round`（论文未涉及跨轮历史视图）。
