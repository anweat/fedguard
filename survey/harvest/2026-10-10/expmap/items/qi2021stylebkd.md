下面全部结论只依据卡片；卡片没有给出的数字一律写“卡片未给”。

## 1. 论文自己的实验规模与主要结果

**场景与规模。** 论文是集中式（centralized）文本分类实验，不涉及联邦学习、不涉及参数高效微调与 LoRA（卡片 §1）。三个受害模型是 BERT（bert-base-uncased，1.1 亿参数）、ALBERT（albert-base-v2，1100 万参数）、DistilBERT（distilbert-base-cased，6500 万参数），均为 base 规模的全参数微调模型；论文在 Ethical Considerations 中明确说“We use the base versions rather than large versions of pre-trained models to save energy.”（卡片 §1、§7）。三个数据集是 SST-2（情感分析，2 类，平均句长 19.3 词，训练 6,920 / 验证 872 / 测试 1,821 条）、HS（仇恨言论检测，2 类，19.2 词，7,074 / 908 / 1,999 条）、AG's News（新闻主题分类，4 类，37.8 词，128,000 / 10,000 / 7,600 条）（卡片 Table 1）。无防御干净准确率（CA）为：SST-2 上 BERT 91.71、ALBERT 88.08、DistilBERT 90.06；HS 上 92.35、90.55、92.50；AG's News 上 91.23、90.99、91.28（卡片 Table 1）。训练超参数是 Adam、初始学习率 2e-5 线性衰减、3 个 epoch（卡片 §5.1）；目标标签为 SST-2 的 Positive、HS 的 Clean、AG's News 的 World（卡片 §5.1）；候选触发风格有五种：Shakespeare、Tweets、Bible、Poetry、Lyrics（卡片 §3.1）。**联邦客户端数与轮次卡片未给**（论文不涉及联邦）；**具体毒化率卡片未给**，论文只说“We tune the poisoning rate ... for each attack method on the validation sets, aiming to make ASR as high as possible and the decrements of CA less than 3%.”（卡片 §5.1）；**随机种子、重复次数与方差卡片未给**。

**后门攻击 StyleBkd 的主要结果。** 无防御时三种攻击的 ASR 全部超过 90 甚至接近 100，同时 CA 保持良好（卡片 §7 后门攻击结果段、§5.2）。StyleBkd 的具体 ASR 为：SST-2 上 BERT 94.70、ALBERT 97.79、DistilBERT 94.04；HS 上 90.67、94.02、90.22；AG's News 上 97.64、95.16、97.96（卡片 Table 4）。消融显示辅助损失 La 有效：在 BERT 与 SST-2 上加入 La 使 ASR 从 92.16 升到 94.70（无防御）、从 91.94 升到 94.59（有防御）（卡片 Table 7）。

**抗 ONION 的结果（论文最核心的防御相关数字）。** 部署 ONION 后，插入式基线 RIPPLES 与 InsertSent 的 ASR 大幅下降，StyleBkd 基本不受影响：SST-2 上 BERT 的 RIPPLES 从 100 降到 24.56、InsertSent 从 100 降到 30.92，StyleBkd 从 94.70 变为 94.59（∆ASR 为 -0.11）；平均 ∆ASR 为 RIPPLES -66.92、InsertSent -45.49、StyleBkd -0.83（卡片 Table 4、§5.2）。论文据此认为，基于数据审查的防御依赖毒化样本的不可见性（卡片 §5.1 引句）。

**不可见性的证据。** 人工数据审查中，StyleBkd 的 Poisoned F1 只有 15.09（Normal F1 87.03、macro F1 51.06），而 RIPPLES 为 85.37 / 96.23 / 90.80、InsertSent 为 83.33 / 95.57 / 89.45（卡片 Table 5、§5.3）。自动质量指标上 StyleBkd 也是三者最优：PPL 161.8、GE 2.51，对比 RIPPLES 的 441.2 / 4.56 与 InsertSent 的 171.9 / 3.89（卡片 Table 5）。人工审查的协议是随机抽 40 个毒化样本加 160 个正常样本让标注者二分类判断（卡片 §5.3）。

**触发风格的选择与效果。** 在 BERT + SST-2 上，探测分类准确率（PCA）为 Bible 94.69、Poetry 93.09、Shakespeare 92.64、Lyrics 92.59、Tweets 78.43，对应 ASR 为 94.70、91.61、91.94、91.49、72.30；Bible 因 PCA 最高被选为最终触发风格（卡片 Table 6、§5.4）。

**对抗攻击 StyleAdv 的主要结果。** SST-2 上对 BERT / ALBERT / DistilBERT 的 ASR 为 91.47 / 95.51 / 96.21，PPL 为 228.7 / 191.9 / 180.7，GE 为 1.15 / 1.16 / 1.13；同数据集上 SCPN 的 ASR 为 52.84 / 59.98 / 64.73，GAN 为 26.42 / 39.40 / 47.53（GAN 因无法在 HS 与 AG's News 上训练出可用生成器，只在 SST-2 上评测，卡片 Table 2、§4.1）。HS 上 StyleAdv 的 ASR 为 51.25 / 59.03 / 31.00，AG's News 上为 58.36 / 80.70 / 89.54（卡片 Table 2）。对抗样本的人工有效性评测只在 SST-2 上做，每种方法随机抽 200 个对抗样本、三名标注者独立投票，有效比例为 GAN 3%、SCPN 43%、StyleAdv 49.5%（卡片 §4.3）。查询预算为每个实例最多查询受害模型 50 次（卡片 §4.1）。

**开销。** 论文未报告任何计算、通信或存储开销的量化数据，没有训练时间、显存、参数量对比或毒化样本生成耗时（卡片 §8）；卡片给出的相关约束只有每实例最多 50 次查询（§4.1）、Adam + 2e-5 + 3 个 epoch（§5.1），以及“运行 STRAP、为每种风格训练一个探测分类器”的定性描述，量级卡片未给。

## 2. 与我们各项实验的对应

先说总体判断：**论文与我们的任何一项实验都不构成 method_source**。我们没有实现或运行 STRAP、StyleBkd、StyleAdv；E6 里我们确实跑了 ONION，而论文也把 ONION 当作外部防御来评测，但 ONION 不是这篇论文提出的方法（卡片 §5.1），所以这不算 method_source。论文是集中式、全参数、base 规模模型、且不提出任何防御组件（卡片 §6“无干预”），因此它也不是我们联邦 LoRA 实验设置的对齐对象；唯一有参照价值的是它的攻击评测口径。

- **E1（挂上库但不运行插件，结果逐位相同）：background**。卡片里没有任何关于训练脚本等价性、插件零干预或宿主框架的内容，与 E1 无对应。
- **E2（两侧采集与插件开销）：background**。卡片明确说论文未报告计算、通信或存储开销的量化数据（§8），只有每实例 ≤50 次查询（§4.1）和 Adam/2e-5/3 epochs（§5.1）这类约束，STRAP 与探测分类器的额外开销量级卡片未给。我们 E2 的 0.7%–2.8%、0.25%–1.8%、ProtegoFed 3.8 秒等数字在论文里没有可对标的参照，既不能印证也不能反驳。
- **E3（效果层/因子层的更新大小与方向特征）：same_question，但不可直接比较**。两者都在问“投毒方留下的痕迹是否可分”：论文问的是毒化样本与正常样本在内容层、在人工审查和 ONION 下是否可分，证据是 Poisoned F1 仅 15.09（Table 5、§5.3）和 ONION 下平均 ∆ASR 仅 -0.83（§5.2）；我们问的是恶意客户端的 LoRA 更新在大小/方向上是否可分，结果是效果层大小 15/20、因子层方向 17/20、效果层方向 3/20。论文完全没有测过“客户端更新”这类可观测量，我们的攻击（MaliciousGen 有害问答、占其数据 100%）也不是风格触发，所以我们的结果不构成对论文结论的反例，论文的结论也不能用来预测我们的检测器在风格触发下的表现。模型（BERT base 全参数 vs Qwen2.5-0.5B + LoRA r=16）、范式（集中式 vs 联邦）、轮数（3 个 epoch vs 20 轮）差距都很大，不能直接比较。
- **E4（良性基线与 1% 误报阈值校准）：same_question + setting_reference**。作为同一个问题，两者都关心“投毒越稀释、越不可见，是否越难检出”：论文的风格触发即使在未知毒化率下也让人工审查（Poisoned F1 15.09）与 ONION（平均 ∆ASR -0.83）基本失效；我们观察到恶意数据占比 100% 时效果层大小 18/18 轮、效果层方向 14/18 轮，占比 30% 时最好 6/18，占比 10% 时只有 1–2/18、与误报相当。方向上相容，但论文具体毒化率卡片未给（§5.1 只说在验证集上调优、要求 CA 降幅小于 3%），我们也没有 ASR，所以只能说“看起来方向一致”，不能互相印证。作为设置参照，论文的评测口径——毒化测试集上的 ASR、原始测试集上的 CA、有/无防御的 ∆ASR 与 ∆CA（Table 4）——正是我们 E4/E5/E6 后续该补的口径，我们目前只报检出轮数，没有 ASR/CA。
- **E5（自动攻击矩阵与行为探针）：same_question，但不可直接比较**。论文的核心主张是“resistance to defenses of backdoor attacks is dependent on their invisibility”（§5.1 引句），我们 E5 的结论是逐轮判定在 ≥30% 恶意占比时检出 83–100%、误报 0.6–1.9%，但分散低浓度（2–3 个恶意客户端各 10%，检出 3–15%）与每轮只抽 5 个客户端（24–35%）时失效；两者都在问“投毒在什么条件下会被漏掉”。但论文的可观测量在文本层与表示层，我们的可观测量是更新统计量与行为探针，论文没有做联邦检测实验、也没有测过聚合更新，双方的数字不能互相印证或反驳。另外值得注意：E5 的行为探针（加载每个客户端更新后测对 AdvBench 有害提示的顺从倾向、跨轮累积后 37 个恶意客户端中 33 个超过全部良性客户端）在方法论上与论文的探测分类任务（为每种风格训练“原句还是风格迁移句”的二分类器得到 PCA，Table 6）同属“训练一个探针判断某属性是否可辨识”，但我们没有实现论文的风格探测流程，所以仍是 background 级别的方法类比，不是 method_source。
- **E6（已发表防御可用性批量，含 ONION 与触发词后门场景 B）：setting_reference**。这是与论文接触最实的一点：ONION 是论文用来评测攻击的外部防御（§5.1、Table 4），E6 也跑了 ONION；E6 场景 B（每个客户端 20% 样本带触发词与固定目标输出）属于插入式后门，正是论文的 RIPPLES/InsertSent 一类基线，而论文给出的参照数字是 ONION 下 SST-2 上 BERT 的 RIPPLES 从 100 降到 24.56、InsertSent 从 100 降到 30.92，平均 ∆ASR -66.92 与 -45.49（Table 4）。但 E6 明确“不评价防御效果”，只有一次样本过滤读数（ProtegoFed 精确率 0.77、召回 0.49，4B，480 条样本中 96 条带毒），所以我们目前无法与论文任何 ∆ASR 数字对照。卡片未给 ONION 的阈值与实现细节（§5.1），因此即便补测，也要先确认两边 ONION 是否同一实现。
- **E7（无攻击对照）：same_question，但不可直接比较**。论文 §5.3 的人工审查同时报告了 Normal F1（StyleBkd 87.03、RIPPLES 96.23、InsertSent 95.57），衡量审查者在正常样本上的误判；我们 E7 衡量的是无攻击时各防御的错误干预率（Krum 排除 80% 客户端轮次、LoMar 65%、FLDetector 20%、MUD-HoG 20%、ONION 改写 59% 样本、梯度谱熵屏蔽 71% 样本等）。两者问的都是“防御/审查侧在良性数据上会不会大量误动作”，但一边是人类标注者、一边是算法防御，指标也不同（F1 vs 排除率/改写率），且我们都是单次运行、论文的种子与重复次数卡片未给，所以只能说是同一问题下的不同侧面，谈不上印证或矛盾。
- **E8（Flower 与 OpenFedLLM 宿主适配）：background**。论文是集中式训练，卡片没有任何关于联邦框架、插件挂载或服务器/客户端协议的内容，没有可对齐的设置。
- **E9（Safe-FedLLM 式 LoRA 权重探针及换种子失效）：background**。论文确实在受害模型表示层外接二分类器判断样本是否被毒化、并据此构造损失 La（§3.3 引句），这是它唯一直接暴露在内部表示上的可观测量；但我们的探针作用在服务器侧聚合权重上、用于给客户端加权，不是训练时的样本级判别器，因此不算 method_source，只能算“都用探针”的远类比。E9 的种子敏感性（同种子下能把恶意客户端聚合权重压低，换一次运行后恶意客户端概率 0.00）也提醒我们需要多种子，而卡片未给论文的种子或重复次数，无从对照。
- **E10（调研与知识库、防御算子流水线映射）：background**。论文没有提出任何检测或防御组件，干预动作为“无”，只在 §7 提出两个尚未实现的设想（训练数据风格迁移增广、测试样本风格迁移），且没有报告这两个设想的任何实验（§6）。因此它对我们“45 篇防御的 481 个步骤对到算子与运行时”的映射没有可直接对表的步骤；它的攻击流程（毒化样本生成、损失改动、推理输入改写）也许可以登记为威胁技术，但卡片没有给出它与我们知识库编号的对应关系，卡片未给。论文是否属于 E10 的 137 篇之一，卡片未给。

## 3. 我们要与它可比还差什么

1. **攻击类型没有对齐。** 论文的触发是 STRAP 文本风格改写（Bible 等五种风格，§3.1、§3.3）；我们只有 MaliciousGen 有害问答（E3/E4/E5）和触发词 + 固定目标输出（E6 场景 B），没有风格迁移触发。要与论文可比，至少要在客户端数据上实现一个“改写输入为触发风格 + 替换目标标签”的毒化流程。
2. **攻击入口少了一个。** 论文的 StyleBkd 还改动训练损失，用外接在表示层的二分类器产生辅助损失 La（§3.3），消融显示 La 把 ASR 从 92.16 抬到 94.70（Table 7）。我们没有任何实验在客户端改动损失项，需要对客户端侧损失组成做钩子并复现 La。
3. **模型与训练后端规模差距大且不可对齐。** 论文是集中式全参数微调的 BERT 1.1 亿 / ALBERT 1100 万 / DistilBERT 6500 万，训练 3 个 epoch（Table 1、§5.1）；我们是联邦 LoRA 的 Qwen2.5-0.5B / Qwen3.5-0.8B / Qwen3.5-4B，2–20 轮、5–10 个客户端。要可比必须先决定是“复现它的集中式 base 模型设置”还是“把它的攻击迁移到联邦 LoRA”，并补上我们清单里缺的 7B 级模型完整训练与 100 轮量级。
4. **数据集与任务口径没有对齐。** 论文用 SST-2 / HS / AG's News 的全量训练集（6,920 / 7,074 / 128,000 条）与 1,821 / 1,999 / 7,600 条测试集（Table 1）。我们目前没有与论文数值的对照复现，也没有相同任务与相同划分下的分类评测。
5. **缺少最关键的 ASR 指标。** 论文的核心数字全是 ASR、CA 与 ∆ASR/∆CA（Table 4、§5.2）。我们完全没有后门攻击成功率评测，E6 明确不评价防御效果，E3–E5 只有检测指标。至少要为 E6 场景 B 与将来的风格触发补“毒化测试集上的 ASR + 原始测试集上的 CA”，并按论文口径分有/无防御报告 ∆ASR 与 ∆CA。
6. **缺少毒化率扫描。** 论文逐攻击方法在验证集上调毒化率，目标是 ASR 尽量高而 CA 下降小于 3%（§5.1，具体数值卡片未给）；我们只有客户端级的 100% / 30% / 10%（E4）与样本级 20%（E6 场景 B）。需要补“样本毒化比例 × 恶意客户端比例”两个维度上的 ASR/CA 曲线。
7. **ONION 这个共有组件缺一个可比的数。** 要与论文的平均 ∆ASR（StyleBkd -0.83、RIPPLES -66.92、InsertSent -45.49，§5.2）对照，必须在我们自己的设置下跑 ONION 并测 ASR；现在 E6/E7 只有 ONION 的可用性与无攻击改写率（59%），而且卡片未给论文 ONION 的阈值与实现细节，需先确认实现一致。
8. **缺少样本级审查与质量指标。** 论文用 GPT-2 的 PPL（StyleBkd 161.8）、LanguageTool 的 GE（2.51）以及人工审查的 Poisoned F1 / Normal F1 / macro F1（15.09 / 87.03 / 51.06，Table 5），审查协议是 40 个毒化样本 + 160 个正常样本（§5.3）。我们唯一接近的是 E6 里 ProtegoFed 的精确率 0.77 / 召回 0.49（4B，480 条样本 96 条带毒），口径不同，缺 PPL、GE 与人工判定。
9. **缺少触发风格选择所需的设施与实验。** 论文需要正常训练样本作探测集，并为每种候选风格训练一个探测分类器得到 PCA（Table 6，Bible 94.69 最高）。我们的库需要干净参考集接口和“逐风格探针”实验，目前两项都没有。
10. **缺少推理期攻击与查询日志实验。** 论文的 StyleAdv 对每个实例最多查询 50 次（§4.1），并做过 200 个对抗样本、三名标注者的人工有效性评测（StyleAdv 有效 49.5%，§4.3）。我们既没有推理期改写攻击实验，也没有查询日志采集实验。
11. **缺少多种子与置信区间。** 论文的种子与重复次数卡片未给，而我们的 E3/E5/E7/E9 多为单种子（E4 有 3 个种子、E5 多数级别 1 个种子、E7/E9 单次）。要与任何一边的数字比较，都需要先补多种子重复与置信区间。
12. **指标维度要保留我们自己的安全项。** 论文的 CA 只是任务准确率，不含安全对齐；而 E4 显示良性微调本身就把 AdvBench 无害率从 81% 压到 49–63%。所以即使为了对齐论文补了 ASR/CA，也不能只用 CA 判断“攻击代价”，否则会丢掉我们已经观察到的安全退化现象，也可能让 E5 的行为探针把良性微调的安全退化误记为投毒信号。
13. **双方都缺自适应攻击。** 论文未评估自适应攻击者（卡片 §9），我们也没做知道防御的自适应攻击、上传侧攻击或合谋。即便补齐上面各项，两边能比较的也只是固定防御下的攻击效果，而不是防御方知情时的效果。
