# ax2106.08283：CRFL（Certifiably Robust Federated Learning，可认证鲁棒联邦学习）

## 1. 方法一句话

CRFL 在联邦训练期由服务器对每轮聚合后的全局模型参数做 ℓ2 范数裁剪（clipping）并叠加各向同性高斯噪声（perturbing），在训练结束后由服务器对最终全局模型做参数平滑（parameter smoothing，即对模型参数而非输入采样加噪），输入是最终裁剪后的全局模型、一个测试样本以及 FL/攻击配置，输出是"预测类别 ĉ_A + 认证半径 RAD"或"ABSTAIN + 0"；它不剔除、不重加权任何客户端，而是给出一个可认证的后门幅度阈值：只要后门幅度小于 RAD，被后门污染模型的预测就与干净模型一致（Corollary 1，Eq. 2；Algorithm 1、Algorithm 2）。

## 2. 运行位置

论文明确"所有操作都在服务器端进行，以降低本地客户端负载并防止恶意客户端"（Section 1），因此客户端侧仍是标准 FedAvg 本地训练，不需要任何额外往返；论文在 Related work 中强调"Our work allows standard FL protocol"（Section 2，与 Cao et al., 2021 的对比）。

- 服务器下发前：服务器把上一轮的噪声全局模型 ẽw_{t−1} 下发给所有客户端（Algorithm 1 中 "The server sends ẽw_{t−1} to the i-th client"）；第 1 轮 ẽw_0 = w_0（Algorithm 1 的 Server's input）。
- 客户端训练前：客户端用 ẽw_{t−1} 初始化本地模型 w^i_{(t−1)τ_i} ← ẽw_{t−1}（Section 4.1；Algorithm 1）。
- 客户端每个训练步：执行 τ_i 步 mini-batch SGD（Section 3.1；Algorithm 1 内层循环）。
- 客户端上传前：客户端只计算并上传相对 ẽw_{t−1} 的更新增量 w^i_{tτ_i} − ẽw_{t−1}，论文没有对客户端上传做裁剪、加噪或过滤（Algorithm 1）。
- 服务器收到更新：直接进入聚合，论文没有对单个客户端更新做检测（Algorithm 1）。
- 服务器聚合：FedAvg 式加权聚合（Section 3.1；Algorithm 1）；论文另外把鲁棒聚合 RFA（Pillutla et al., 2019）作为聚合规则的替换项来评估 CRFL 认证半径（Section 6.2，Figure 6），但 RFA 不是本文提出的方法。
- 聚合之后：服务器先裁剪范数，再在 t ≤ T−1 时加高斯噪声，得到下一轮广播模型；最后一轮（t = T）只裁剪（Section 4.1；Algorithm 1）。
- 训练之外：测试时服务器做参数平滑、Monte Carlo 投票、Hoeffding 置信界与认证半径计算，输出预测或 ABSTAIN（Section 4.2；Algorithm 2）。
- 额外往返：不需要（论文未设计任何额外通信轮次）。

## 3. 算子流水线

以下按执行顺序给出。记号沿用论文：w ∈ R^d 为模型参数，N 为客户端数，p_i 为第 i 个客户端的聚合权重，η_i 为本地学习率，τ_i 为每轮本地迭代步数，n_Bi 为 mini-batch 大小，q_Bi 为攻击者每批加入的后门样本数，γ_i 为攻击者的缩放因子，t_adv 为攻击轮，T 为总轮数，ρ_t 为第 t 轮裁剪阈值，σ_t 为训练期噪声标准差，σ_T 为测试期平滑噪声标准差，R 为攻击者数量，δ_i 为第 i 个攻击者的后门，L_Z 为梯度对数据的 Lipschitz 常数。

**步骤 1：服务器下发（噪声）全局模型**
- 输入：服务器持有的全局参数 ẽw_{t−1} ∈ R^d；t = 1 时为初始模型 w_0（Algorithm 1 Server's input 给出 ẽw_0 ← w_0）。
- 计算：把 ẽw_{t−1} 原样广播给全部 N 个客户端。
- 输出：每个客户端本轮的初始化模型 ẽw_{t−1}。
- 出处：Algorithm 1 "The server sends ẽw_{t−1} to the i-th client"；Section 4.1。

**步骤 2：客户端本地 mini-batch SGD**
- 输入：初始化 w^i_{(t−1)τ_i} = ẽw_{t−1}，本地数据集 S_i（大小 n_i），学习率 η_i，本地步数 τ_i；每步从 S_i 随机采样 mini-batch ξ^i_{s−1} ⊂ S_i，批大小 n_Bi。
- 计算：对 s = (t−1)τ_i+1, …, tτ_i 依次执行 ∇ 与更新：g_i(w^i_{s−1}; ξ^i_{s−1}) = (1/n_Bi) Σ_{z ∈ ξ^i_{s−1}} ∇ℓ(w^i_{s−1}; z)，w^i_s ← w^i_{s−1} − η_i·g_i(w^i_{s−1}; ξ^i_{s−1})。
- 输出：本地模型 w^i_{tτ_i}。
- 出处：Section 3.1（Periodic Averaging SGD 的公式）；Algorithm 1 内层循环。

**步骤 3：客户端计算并上传更新增量**
- 输入：本地模型 w^i_{tτ_i} 与本轮初始化 ẽw_{t−1}。
- 计算：Δ^i_t = w^i_{tτ_i} − ẽw_{t−1}，注意基准是带噪广播模型而不是上一轮聚合模型 w_{t−1}。
- 输出：每个客户端一个 d 维增量（论文未说明是否压缩或量化）。
- 出处：Algorithm 1 "The i-th client sends w^i_{tτ_i} − ẽw_{t−1} to the server"；Section 3.1。

**步骤 4：服务器加权聚合**
- 输入：N 个更新 Δ^i_t ∈ R^d，聚合权重 p_i（满足 p_i ≥ 0 且 Σ_{i=1}^N p_i = 1，Section 3.1）。
- 计算：w_t ← ẽw_{t−1} + Σ_{i=1}^N p_i·(w^i_{tτ_i} − ẽw_{t−1})；当 Σp_i = 1 时等价于对本地模型做凸组合 w_t = Σ_i p_i·w^i_{tτ_i}。
- 输出：本轮聚合全局模型 w_t ∈ R^d。
- 出处：Algorithm 1 "The server updates the model parameters"；Section 3.1。

**步骤 5：服务器裁剪聚合模型的 ℓ2 范数**
- 输入：w_t ∈ R^d，阈值 ρ_t。
- 计算：Clip_{ρ_t}(w_t) ← w_t / max(1, ‖w_t‖₂/ρ_t)；论文中 ‖·‖ 一律指 ℓ2 范数。ρ_t 随轮次自适应增大（Appendix A.1：为了让模型保留正常学习能力），具体调度见表 1。
- 输出：范数不超过 ρ_t 的裁剪模型 Clip_{ρ_t}(w_t)。
- 出处：Section 4.1；Algorithm 1 "The server clips the model parameters"；Table 1。

**步骤 6：服务器加各向同性高斯噪声（仅当 t ≤ T−1）**
- 输入：Clip_{ρ_t}(w_t)，噪声标准差 σ_t。
- 计算：采样 ε_t ~ N(0, σ_t²·I)（逐坐标独立噪声），ẽw_t ← Clip_{ρ_t}(w_t) + ε_t；若 t = T 则跳过本步。
- 输出：下一轮广播模型 ẽw_t ∈ R^d。
- 出处：Section 4.1 "add isotropic Gaussian noise ϵt ∼ N(0, σ2 t I) directly on the aggregated global model parameters (coordinate-wise noise)"；Algorithm 1 的 if t ≤ T−1 分支。

**步骤 7：最后一轮只裁剪，输出最终全局模型**
- 输入：最后一轮聚合模型 w_T。
- 计算：M(D) := Clip_{ρ_T}(w_T)（论文把整个训练协议记为 M）。
- 输出：最终裁剪后的全局模型参数 Clip_{ρ_T}(w_T)。
- 出处：Section 4.1 "In the final round T, we only clip the global model parameters"；Algorithm 1 的 Output。

**步骤 8：测试期参数平滑（生成 M 个噪声模型）**
- 输入：Clip_{ρ_T}(w_T)，平滑噪声标准差 σ_T，采样个数 M。
- 计算：独立采样 ε^k_T ~ N(0, σ_T²·I)，ẽw^k_T ← Clip_{ρ_T}(w_T) + ε^k_T；论文要求与训练期高斯噪声对齐，取平滑测度 µ(w) = N(w, σ_T²I)。Algorithm 2 的伪代码写的是 k = 0, 1, …, M，正文说"M 次""M sets"并按 M 归一化，两者相差一个样本（见第 9 节）。
- 输出：M 个（伪代码为 M+1 个）噪声模型参数 {ẽw^1_T, …, ẽw^M_T}。
- 出处：Section 4.2；Algorithm 2 第一段循环；Eq. 1。

**步骤 9：对单个测试样本做投票计数**
- 输入：测试样本 x_test，M 个噪声模型参数，基础分类器 h(·, ·)。
- 计算：对每个 k 运行 h(ẽw^k_T; x_test)，统计每一类 c ∈ Y 的票数，得到计数向量 counts ∈ N^C（函数 GetCounts）；取票数最高类 ĉ_A 与次高类 ĉ_B，ˆp_A = counts[ĉ_A]/M，ˆp_B = counts[ĉ_B]/M。分类器定义见 Eq. 1：h_s(w; x_test) = arg max_{c∈Y} H^c_s(w; x_test)，其中 H^c_s(w; x_test) = P_{W~µ(w)}[h(W; x_test) = c]。
- 输出：ĉ_A、ĉ_B、ˆp_A、ˆp_B。
- 出处：Section 4.2；Algorithm 2 的 GetCounts 与 ˆp 计算行；Eq. 1。

**步骤 10：Hoeffding 置信界（CalculateBound）**
- 输入：ˆp_A、ˆp_B、误差容忍 α、Monte Carlo 样本数。
- 计算：用 Hoeffding 不等式把经验估计校准为下界与上界：p_A = ˆp_A − √(log(1/α)/(2N))，p_B = ˆp_B + √(log(1/α)/(2N))——论文原文分母写作 2N（N 在全文里是客户端数），从上下文看应为 Monte Carlo 样本数 M，见第 9 节。
- 输出：p_A、p_B ∈ [0,1]。
- 出处：Section 4.2 CalculateBound 段；Algorithm 2 "Calculate lower and upper bounds of pA, pB"。

**步骤 11：接受或弃权判定**
- 输入：p_A、p_B。
- 计算：若 p_A > p_B，则接受预测 ĉ_A 并进入步骤 12；否则输出 ABSTAIN 与 RAD = 0。注意定理前提要求 H^{c_A}_s(M(D′); x_test) ≥ p_A ≥ p_B ≥ max_{c≠c_A} H^c_s(M(D′); x_test)。
- 输出：预测 ĉ_A（或 ABSTAIN）与是否继续计算半径。
- 出处：Algorithm 2 的 if pA > pB 分支；Theorem 1 与 Theorem 3 的前提条件。

**步骤 12：计算认证半径 RAD（CalculateRadius）**
- 输入：p_A、p_B，以及 σ_{t_adv}、L_Z、R、p_i、γ_i、τ_i、η_i、q_Bi/n_Bi、ρ_t、σ_t（t = t_adv+1…T）和 T。
- 计算：Corollary 1（Eq. 2）给出 RAD = √( [ −log(1 − (√p_A − √p_B)²)·σ²_{t_adv} ] / [ 2·R·L_Z²·Σ_{i=1}^R (p_i·γ_i·τ_i·η_i·q_Bi/n_Bi)² · Π_{t=t_adv+1}^{T} (2Φ(ρ_t/σ_t) − 1) ] )，其中 Φ 是标准高斯 CDF。更一般地，Theorem 1 对每个攻击者各自的后门幅度 ‖δ_i‖ 给出条件：R·Σ_{i=1}^R (p_i·γ_i·τ_i·η_i·(q_Bi/n_Bi)·‖δ_i‖)² ≤ [ −log(1 − (√p_A − √p_B)²)·σ²_{t_adv} ] / [ 2·L_Z²·Π_{t=t_adv+1}^{T}(2Φ(ρ_t/σ_t) − 1) ]。对多类逻辑回归，Lemma 1 给出闭式 L_Z = √(2 + 2ρ + ρ²)，其中 ‖w‖ ≤ ρ。
- 输出：认证半径 RAD；语义是当所有攻击者后门幅度满足 ‖δ‖ < RAD 时 h_s(M(D′); x_test) = h_s(M(D); x_test) = ĉ_A。
- 出处：Corollary 1 与 Eq. 2；Theorem 1；Section 4.2 "The function CalculateRadius in our Algorithm 2 can calculate the certified radius RAD according to Corollary 1"；Lemma 1；Appendix A.1（L_Z 用 ρ_{t_adv} 计算）。

## 4. 采样与规模控制

- 样本（samples）：客户端每个本地步从本地数据集 S_i 随机采样 mini-batch ξ^i_s，批大小 n_Bi（Section 3.1；Algorithm 1）。攻击者每个 batch 固定混入 q_Bi 条后门样本，使毒化比例等于 q_Bi/n_Bi = q_i/n_i（Section 3.2）。n_Bi 的具体数值论文未说明，只给出比值 q_Bi/n_Bi（Table 1：LOAN 40/800，MNIST 5/100，EMNIST 5/200）。
- 客户端（clients）：论文未对客户端做抽样，Algorithm 1 每轮遍历全部 i = 1, …, N；N 的取值 LOAN 20、MNIST 20、EMNIST 50（Table 1）。注意 Appendix A.1 又说 LOAN 按 51 个州划分、每州一个客户端，与 Table 1 的 N = 20 不一致（见第 9 节）。
- 层（layers）：论文未使用。裁剪和加噪作用在整个 d 维参数向量上，没有做逐层处理或层选择（Section 4.1；Algorithm 1）。
- 参数坐标（coordinates）：论文未做坐标选择或降维，但噪声是"逐坐标"独立同分布的高斯噪声（Section 4.1 的 coordinate-wise noise），即对全部 d 个坐标都加噪。
- 轮次（rounds）：论文未对轮次抽样。认证公式在 t = t_adv+1, …, T 上做连乘（Eq. 2；Theorem 2），T 在图 8（LOAN：30/50/60/80；EMNIST：20/50/70/100/130/150）与 Figure 13(c)（MNIST：50/70/100）中变化，默认 T 论文未说明（只说"train the FL global model until convergence"，Section 6.1）。
- 探针（probes）：测试期用 M 个噪声模型副本做 Monte Carlo 估计，M = 1000（Section 6.1），并在 Figure 11（左）中比较 M = 100/500/1000/2000/5000；误差容忍 α = 0.001（Section 6.1），Figure 11（中）给出 99%/99.9%/99.99%/99.999% 四档置信度。评测时抽取 10000/5000/10000 个测试样本（LOAN/MNIST/EMNIST，Section 6.1）。CRFL 不使用任何干净参考数据或探针数据集。

## 6. 判定与动作

- 训练期没有"检测判定"，动作是固定的模型变换：每轮对聚合模型做 Clip_{ρ_t}(w_t) = w_t/max(1, ‖w_t‖₂/ρ_t)，若 t ≤ T−1 再加 ε_t ~ N(0, σ_t²I)，并把 ẽw_t = Clip_{ρ_t}(w_t) + ε_t 作为下一轮广播模型；t = T 只裁剪（Section 4.1；Algorithm 1）。这相当于"裁剪 + 加噪 + 广播变换"三个动作，且完全不依赖对客户端的判定，不剔除、不重加权、不修改客户端上传。
- 测试期判定规则：先按 Hoeffding 界得到 p_A、p_B（α = 0.001）；若 p_A > p_B，则输出预测 ĉ_A 并计算 RAD；否则输出 ABSTAIN 且 RAD = 0（Algorithm 2）。
- 阈值语义：RAD 本身就是阈值。Corollary 1 说明当所有攻击者的后门幅度满足 ‖δ‖ < RAD 时，h_s(M(D′); x_test) = h_s(M(D); x_test) = c_A，即预测在后门幅度不超过 RAD 时被认证不变（Eq. 2）。界内的收缩量来自 √(log(1/α)/(2N))（原文分母，见第 9 节），α = 0.001。
- 裁剪/加噪幅度：ρ_t 按数据集特定调度（Table 1），训练噪声 σ_t = 0.01，测试平滑噪声 σ_T = 0.01。
- 是否跨轮累积：判定本身逐测试样本独立、不跨轮累积；但认证半径的分母跨轮累积收缩因子 Π_{t=t_adv+1}^{T}(2Φ(ρ_t/σ_t) − 1)（Eq. 2；Theorem 2 与 Appendix Eq. 13），并且训练期每一轮的噪声都会真实注入模型、影响其后所有轮（Algorithm 1）。对攻击者的求和 Σ_{i=1}^R 与因子 R 是跨客户端累积，不是跨轮。论文的口径是"服务器不知道模型是否被污染，假设它已被后门化，再推导其预测与干净模型一致的条件"（Theorem 1 后的说明；Theorem 3 证明）。

## 7. 需要的外部资源

- 不需要干净参考数据、根数据集（root dataset）、预训练检测器或额外的判别模型；只需基础分类器 h 和 FL 训练出的全局模型。论文强调与 RAB（Weber et al., 2020）不同：RAB 要用 M 个噪声污染数据集训练 M 个模型，CRFL 只通过 FL 训练一个模型，然后生成 M 个噪声副本（Section 4.2）。
- 认证公式需要服务器已知（或能代入）下列量：攻击轮 t_adv、攻击者数量 R、每个攻击者的 γ_i、τ_i、η_i、q_Bi/n_Bi（或其上界）、σ_{t_adv}、每轮 ρ_t 与 σ_t、总轮数 T，以及由 ρ 计算的 L_Z（Corollary 1；Appendix A.1）。论文没有说明这些量在真实部署中如何获得。
- 规模：模型维度 d，认证期需要 M 个 d 维噪声副本（Section 4.2）；实验规模为 N = 20/20/50，τ_i = 143/30/70，特征维度 91/784/784（Table 1；Appendix A.1）。

## 8. 计算与存储开销

- 论文报告的开销相关内容：测试期 CRFL 只需对模型加 M 次噪声，而输入平滑（randomized smoothing）需要对测试样本加 m·M 次噪声（m 为测试集大小），即"during testing, there are m · M times noise addition on test samples for randomized smoothing, and M times noises addition on trained model for CRFL"（Section 4.2）；训练期只需训练一个 FL 模型而不是 M 个（Section 4.2）。论文还报告了数值性问题：Π(2Φ(ρ_t/σ_t) − 1) 在实践中不会趋于 0，因此 T 增大时 RAD 不再增大（Section 5.1 的 remark 2、Section 6.2 与 Figure 9(b)），并建议若要增大 T 来提升认证半径就应让 ρ/σ 小于某个阈值。抽取出的全文中没有给出运行时或显存的具体数值；Appendix 开头的目录声称 Appendix A 会给出 "runtime of attacks"，但对应附录正文中没有相应数字（Appendix 引言与 A.2）。
- 分析：主要开销在客户端本地 SGD——每轮 N 个客户端各做 τ_i 个本地步、每步一次 mini-batch 前向与反向传播，共 T 轮，量级随 N·τ_i·T 增长；服务器每轮的额外开销只是 O(d) 的范数裁剪与逐坐标加噪（Algorithm 1）。认证阶段的主要开销是每个测试样本 M 次前向传播（m 个样本共 m·M 次），随 M 与测试集规模线性增长（Algorithm 2；Section 4.2）。存储上需要保存 M 个 d 维噪声模型副本（或等价的 M 条 d 维噪声向量），空间为 O(M·d)（分析，依据 Section 4.2 "M noise-corrupted copies of it"）。

## 9. 实现时容易错的地方

论文明确强调或存在出入、实现时必须注意的点：

1. 客户端上传的更新基准是本轮的带噪广播模型 ẽw_{t−1}，而不是上一轮聚合模型 w_{t−1}；服务器聚合公式也是 w_t ← ẽw_{t−1} + Σ p_i(w^i_{tτ_i} − ẽw_{t−1})（Algorithm 1）。若实现成经典 FedAvg 的 w_{t−1} + Σp_i(w^i_{tτ_i} − w_{t−1})，会与论文的马尔可夫核分析和认证界不一致。
2. 最后一轮不加噪，只裁剪：Algorithm 1 用 if t ≤ T−1 控制加噪分支，最终输出是 Clip_{ρ_T}(w_T)（Section 4.1；Algorithm 1）。
3. CalculateBound 的分母在原文里写作 2N：p_A = ˆp_A − √(log(1/α)/(2N))，p_B = ˆp_B + √(log(1/α)/(2N))（Section 4.2）；但 N 在全文里表示客户端数，Hoeffding 界应当用 Monte Carlo 样本数 M，且 Algorithm 2 中 ˆp = counts/M。实现时须自行决定采用 M，论文未说明这一处是否笔误。
4. Algorithm 2 的循环写作 "for k = 0, 1, . . . M"，会产生 M+1 个噪声模型，而正文说 M 次、M sets，并除以 M（Section 4.2）。逐个实现时会差一个样本，论文未说明。
5. 置信界的收缩量与 α 有关：α = 0.001 对应 99.9% 置信度（Section 6.1；Figure 11 中）；论文观察到认证半径对 α 不很敏感，但 α 越小半径越小（Appendix A.2）。
6. RAD 公式的分子用的是攻击轮的训练噪声 σ²_{t_adv}，不是测试噪声 σ²_T（Eq. 2；Theorem 2）；把 σ_T 代进去是常见错误。
7. 连乘项 Π_{t=t_adv+1}^{T}(2Φ(ρ_t/σ_t) − 1) 有数值下溢风险：论文明确说该连乘在实践中不会趋于 0，导致 RAD 不再随 T 增长，并建议让 ρ/σ 保持在阈值以下（Section 5.1 remark 2；Section 6.2；Figure 9(b)）。论文没有给出处理下溢的具体实现方案。
8. L_Z 的计算：Lemma 1 的闭式 √(2+2ρ+ρ²) 只对多类逻辑回归（一层线性 + softmax + 交叉熵）成立，且实验里当 ρ_t 是变化值时应"基于 ρ_{t_adv}"计算（Appendix A.1）；Figure 11（右）为控制变量对所有 t_adv 都用了基于 ρ_44 的宽松 L_Z。对一般神经网络，论文明确说对数据输入的 Lipschitz 梯度常数的高效计算仍是开放问题（Section 5.1 remark 5）。
9. 理论前提：需要损失函数凸且 β-光滑、梯度对数据 L_Z-Lipschitz、η_i ≤ 1/β（Assumption 1、2、3；Theorem 1）。实验只做凸的多类逻辑回归；β 的数值论文未报告。深度模型能否直接套用论文未说明。
10. 认证假设服务器已知 t_adv、R 以及攻击者的 γ_i、τ_i、η_i、q_Bi/n_Bi；论文未给出这些量的估计方法，把它们当作已知条件代入（Corollary 1；Appendix A.1）。
11. 判定流程的边界情况：counts 最高两类票数相等（ĉ_A、ĉ_B 无法唯一确定）、p_A < p_B（算法给 ABSTAIN）、以及是否检查 Definition 1 要求的 p_A + p_B ≤ 1，论文均未说明（Algorithm 2；Definition 1）。
12. 噪声模型是否每个测试样本重采：正文说 M 个噪声模型一旦生成就固定、对所有测试样本复用（Section 4.2），但 Algorithm 2 的伪代码把采样循环写在每次认证过程内部，逐样本看像是重采。论文两种表述并存。
13. 聚合权重 p_i、mini-batch 大小 n_Bi 的具体数值、默认总轮数 T、优化器细节论文均未说明（Section 3.1；Table 1；Section 6.1 只说训练到收敛）。
14. 数据集设置的内部不一致：Appendix A.1 说 LOAN 按 51 个州划分、每州一个客户端，Table 1 却写 N = 20；Table 1 写 91 个特征，脚注说预处理后保留 90 个特征并归一化到 [0,1]。
15. Table 2 的记号表把 M(·) 描述为"the training protocol in Algorithm 2"，但正文 Section 4.1 明确 M 是 Algorithm 1 的训练协议；引用记号时不要跟错。
