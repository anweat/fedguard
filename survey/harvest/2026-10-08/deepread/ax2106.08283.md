# ax2106.08283：CRFL: Certifiably Robust Federated Learning against Backdoor Attacks

## 1. 基本信息

- **场景（setting）**：传统联邦学习（classic federated learning, FL）。论文采用标准的周期性平均 SGD（Periodic Averaging SGD / FedAvg）协议，客户端本地训练、服务器聚合更新（第 3.1 节）。论文全文没有出现大语言模型（LLM）、LoRA、参数高效微调（PEFT）或适配器（adapter）相关内容，属于小型凸模型的联邦学习，不是联邦大模型微调。
- **训练阶段**：防御跨越两个阶段：训练期（每一轮服务器聚合后做参数裁剪与加噪，见第 4.1 节与 Algorithm 1）与测试/推理期（对最终全局模型做参数平滑并给出逐样本认证，见第 4.2 节与 Algorithm 2）。被防御的攻击发生在训练期的某一轮 tadv。
- **论文类型**：防御（defense），具体是首个针对联邦学习后门攻击的"可认证鲁棒性"（certified robustness）框架；摘要同时声称给出了联邦学习中后门认证鲁棒性的首个基准（"provide the ﬁrst benchmark for certiﬁed robustness against backdoor attacks in federated learning"，Abstract）。它不做攻击检测，不识别恶意客户端。
- **模型与数据规模**：模型是多类逻辑回归（multi-class logistic regression，即一个线性层加 softmax 与交叉熵损失），论文明确称其为凸分类问题（第 6.1 节、附录 A.1）。数据集与规模（Table 1，附录 A.1）：
  - LOAN（Lending Club Loan Data）：9 类，1,446,827 条训练样本，91 维特征，客户端数 N=20，毒化比例 qBi/nBi=40/800，本地迭代 τi=143，缩放因子 γi=10，攻击轮 tadv=6，裁剪阈值 ρt=0.025t+2。正文另称该数据集共 1,808,534 条样本、按 51 个美国州划分给客户端（附录 A.1）。
  - MNIST：10 类，60,000 条训练样本，784 维特征，N=20，qBi/nBi=5/100，τi=30，γi=10，tadv=10，ρt=0.1t+2。
  - EMNIST：47 类（10 个数字与 37 个字母），697,932 条训练样本，784 维特征，N=50，qBi/nBi=5/200，τi=70，γi=20，tadv=10，ρt=0.25t+4。
  - 认证在 LOAN/MNIST/EMNIST 测试集上分别取 10,000/5,000/10,000 个样本（第 6.1 节）。
  - 分析：正文明说 LOAN"按 51 个州划分、每州是一个客户端"，而 Table 1 写 N=20，论文未说明这两个数字如何对应。

## 2. 威胁模型

- **攻击者是谁**：恶意客户端。论文写"Suppose there are R adversarial clients out of N clients"，即 N 个客户端中有 R 个攻击者（第 3.2 节）。
- **占比或数量**：攻击者数量以 R 表示，默认实验设置 R=1（附录 A.1），图中考察 R∈{1,2,3,4}（Figure 5、Figure 6、Figure 12(a)(b)）。论文没有以百分比形式给出恶意比例。分析：按 Table 1 的 N 与默认 R=1 推算，MNIST/LOAN 约为 5%、EMNIST 约为 2%，但论文本身没有写这个百分比。
- **能力（能改什么）**：攻击者只能做三件事——(1) 在自己的本地数据集里加入后门，即把样本 zi={xi,yi} 变成 z′i={xi+δix, yi+δiy}，其中 δix 是输入后门模式、δiy 是标签翻转效果；(2) 在攻击轮 tadv 用被投毒的本地数据集做本地迭代（每个 batch 混入固定数量 qBi 个后门样本，mini-batch 梯度为干净样本梯度与后门样本梯度的混合）；(3) 上传前把恶意本地更新乘以缩放因子 γi，即发送 γi(w′i_{tadvτi} − w_{tadv−1})（第 3.2 节）。论文假设"the whole FL system follows Algorithm 1 to train and Algorithm 2 to test"（Assumption 3），即攻击者不能改变训练/测试协议本身。
- **知识（知道什么）**：论文未系统列出攻击者的知识假设。从流程看，攻击者持有服务器下发的全局模型并用它初始化本地模型，知道自己的本地数据、毒化比例 qBi/nBi、缩放因子 γi 与本地训练超参数（τi、ηi）（第 3.2 节、Table 1）。论文未说明攻击者是否知道其他客户端的更新、服务器的 ρt/σt 配置，或是否针对认证机制做优化。攻击是"distributed yet coordinated"的，即 R 个攻击者在同一轮 tadv 协同行动（第 3.2 节，引用 Xie et al., 2019）。
- **目标**：定向后门（targeted backdoor）。论文的定义是：在训练中注入后门模式，使任何带该模式的测试输入被误分类为目标标签，同时全局模型在未被篡改的数据上表现正常（"the global model would behave normally on untampered data samples while achieving high attack success rate on backdoored data samples"，第 3.2 节）。实验中的目标标签：MNIST/EMNIST 是"digit 0"；LOAN 是"Does not meet the credit policy. Status:Fully Paid"（附录 A.1）。论文还在第 5.1 节"Defend against Other Potential Attack"中讨论了 fixed-frequency attack 与 edge-case/semantic attack（Wang et al., 2020），但只是讨论推广可能性。
- **防御者是谁、能看到什么、信任什么**：防御者是中心服务器。服务器能看到每个客户端上传的本地模型更新，能设置裁剪阈值 ρt、训练期噪声 σt、测试期噪声 σT、蒙特卡洛样本数 M 与错误容忍度 α（第 4.1、4.2、6.1 节）。服务器不需要知道哪些客户端恶意，不做客户端识别；它"does not know the global model in the current FL system is poisoned or not"，因此直接假设模型已经被后门化，再推导其预测与干净模型预测一致的条件（第 5.1 节）。所有防御操作都放在服务器端（"all of the operations are conducted on the server side to reduce the load for local clients and to prevent malicious clients"，第 1 节）。服务器信任的是：全体参与者遵守 Algorithm 1 与 Algorithm 2（Assumption 3）；从而 R、γi、qBi/nBi、||δi||、tadv 等量在认证计算中作为已知或给定上界使用。论文未说明服务器如何获得这些攻击者参数。

## 3. 攻击入口与流程位置

本文是防御论文，下面先写它所针对的攻击入口（这也是攻击者实际动手的位置），再写防御自身介入的位置。

**所针对的攻击入口**：攻击同时进入三个位置——本地数据准备、本地训练过程、更新上传前的后处理；其效果在服务器聚合时体现。

1. **本地数据准备**：攻击者在自己的本地数据集 S′i 中把 qi 个样本替换为后门版本（加模式 δix、翻标签 δiy），毒化比例为 qBi/nBi = qi/ni（第 3.2 节）。
2. **本地训练过程**：在攻击轮之前的轮次，攻击者用干净数据正常训练以免暴露；到 t = tadv 时，攻击者 i 用 w′i_{(t−1)τi} = w_{tadv−1} 初始化，然后对每个本地迭代 s 采样投毒 mini-batch ξ′i，执行 w′i_s ← w′i_{s−1} − ηi gi(w′i_{s−1}; ξ′i_{s−1})，其中 gi 是混合了 qBi 个后门样本的 mini-batch 梯度（第 3.2 节）。论文指出本地迭代越多，恶意本地模型偏离对应的良性本地模型越远。
3. **更新上传前的后处理**：攻击者把恶意本地更新按 γi 缩放后再上传（第 3.2 节）。
4. **服务器聚合**：服务器按 FedAvg 把恶意与良性更新一起聚合，得到被感染的全局模型 w′t ← wt−1 + Σ_{i=1}^{R} piγi(w′i_{tτi} − wt−1) + Σ_{i=R+1}^{N} pi(wi_{tτi} − wt−1)（第 3.2 节）。论文强调即使攻击者在 t>tadv 之后重新使用干净数据，全局模型从 tadv 起就已被感染。

**防御进入的位置**：训练期在服务器聚合之后、全局模型下发之前（裁剪 + 加噪，第 4.1 节）；测试/部署期在推理之前（参数平滑 + 认证，第 4.2 节）。攻击不进入评估与部署阶段；该阶段的认证是用来判断预测是否可信。

## 4. 方法原理

CRFL 由训练期子程序（Algorithm 1）与测试期子程序（Algorithm 2）组成（第 4 节）。

**训练期：裁剪与扰动（Clipping and Perturbing，第 4.1 节）**。每一轮 t=1,…,T−1，服务器先按 FedAvg 聚合本地更新得到 wt，然后裁剪：Clipρt(wt) = wt / max(1, ∥wt∥/ρt)，把参数范数限制在 ρt 内；再在聚合后的全局模型参数上逐坐标加入各向同性高斯噪声 ϵt ∼ N(0, σt²I)，得到下发模型 w̃t ← Clipρt(wt) + ϵt。客户端下一轮用 w̃t 初始化本地模型。最后一轮 T 只裁剪、不加噪，输出 ClipρT(wT)，记为 M(D)。

**测试期：参数平滑（Parameter Smoothing，第 4.2 节）**。论文第一次把随机平滑从输入空间搬到模型参数空间。定义平滑分类器 hs(w; xtest) = argmax_{c∈Y} H^c_s(w; xtest)，其中 H^c_s(w; xtest) = P_{W∼µ(w)}[h(W; xtest) = c]（式 (1)），平滑测度取 µ(w) = N(w, σT²I)，与训练期加噪对齐。实际用蒙特卡洛近似：在 ClipρT(wT) 上独立加 M 次噪声 ϵ^k_T ∼ N(0, σT²I)，得到 M 组加噪模型 w̃^k_T；对每个测试样本跑这 M 个模型，得到逐类计数 counts，取最高与次高类 ĉA、ĉB 及其频率 p̂A、p̂B；用 Hoeffding 不等式把经验估计校正为下界 pA = p̂A − √(log(1/α)/(2N)) 与上界 pB = p̂B + √(log(1/α)/(2N))（论文原文分母写作 2N，Algorithm 2 里 CalculateBound 的参数也写作 N；分析：这里应当是蒙特卡洛样本数 M，论文未说明该记号冲突）。若 pA > pB，则按 Corollary 1 计算认证半径 RAD 并输出预测 ĉA；否则输出 ABSTAIN 与半径 0（Algorithm 2）。

**认证推导链条（第 5 节）**：

- 把每一轮 CRFL（SGD、裁剪、加噪）看成一个马尔可夫核（Markov Kernel），用 f-散度（f-divergence）度量良性训练过程与后门训练过程的模型分布距离；由于 tadv 之后所有客户端（含攻击者）都用干净数据，两个过程共用同一个核，散度按核的收缩系数逐轮收缩（第 5.2 节）。Theorem 2 给出 KL 散度上界，形式为：分子正比于 2R·Σi(piγiτiηi·(qBi/nBi)·LZ·∥δi∥)²，分母为 σ²_tadv，再乘以 ∏_{t=tadv+1}^{T}(2Φ(ρt/σt) − 1)，其中 Φ 是标准高斯累积分布函数。
- Theorem 3 把模型分布的 KL 距离与预测一致性连起来：若 H^{cA}_s(w′; xtest) ≥ pA ≥ pB ≥ max_{c≠cA} H^c_s(w′; xtest)，则对所有满足 DKL(µ(w), µ(w′)) ≤ ϵ 的 w 都有 hs(w′; xtest) = hs(w; xtest) = cA，其中 ϵ = −log(1 − (√pA − √pB)²)。
- Theorem 1（一般鲁棒性条件）把两者合并，给出关于后门幅度 {δi} 的条件式；Corollary 1 在假设所有攻击者后门幅度相同（∥δ∥=∥δi∥）时给出特征级（feature level）认证半径，即式 (2)：

  RAD = √[ −log(1 − (√pA − √pB)²)·σ²_tadv / ( 2R·LZ²·Σ_{i=1}^{R}(piγiτiηi·qBi/nBi)²·∏_{t=tadv+1}^{T}(2Φ(ρt/σt) − 1) ) ]。

- Lemma 1 给出多类逻辑回归在 ∥w∥≤ρ 下损失对数据输入的 Lipschitz 梯度常数 LZ = √(2 + 2ρ + ρ²)。
- 论文给出的定性结论（第 5.1 节 Corollary 1 的 remark）：σt 大、ρt 小、pA 与 pB 的间隔大、攻击者数量 R 小、毒化比例小、缩放因子 γi 小、攻击者聚合权重 pi 小、本地迭代 τi 少、本地学习率 ηi 小时，认证半径 RAD 更大；由于 0 ≤ 2Φ(·)−1 ≤ 1，理论上 T→∞ 时 RAD→∞（后门注入轮之后的良性微调会削弱投毒效果），但实际受数值精度限制，连乘项不会真的趋于 0。
- 认证分三个层级：特征级、样本级、客户端级（第 2 节、第 5.1 节）。

## 5. 检测或防御所需的数据

CRFL 不做检测，它需要的数据全部在服务器端，且不需要客户端原始数据、逐样本损失或梯度。逐项如下：

1. **各客户端上传的本地模型更新**（本地训练后的本地模型与上一轮下发全局模型之差 wi_{tτi} − w̃_{t−1}）。
   - 采集位置：服务器收到更新时（server_receive）。
   - 粒度：逐客户端、逐轮。
   - 是否需要跨轮历史：否。是否需要干净参考数据或根数据集：否。是否需要额外前向/反向计算：否。
   - 说明：这是 FedAvg 聚合本身需要的输入；CRFL 的裁剪与加噪作用在聚合结果上，所以 CRFL 自己不检查单个更新。若把鲁棒聚合规则（如 RFA）嵌进来，则需要这些逐客户端更新的两两距离/中位数等统计（第 6.2 节）。
2. **聚合后的全局模型参数 wt 及其裁剪结果 Clipρt(wt)**。
   - 采集位置：服务器聚合之后（server_post_aggregate），每轮一次。
   - 粒度：模型级（整个参数向量，逐坐标加噪）。
   - 跨轮历史：否。干净参考数据：否。额外计算：裁剪与逐坐标加噪各一次。
3. **每轮的裁剪阈值 ρt 与噪声水平 σt（以及测试期 σT）**。
   - 采集位置：服务器端配置/调度（server_post_aggregate 时使用）。
   - 粒度：逐轮。
   - 跨轮历史：是（ρt 随时间递增，Table 1 给出 LOAN 为 0.025t+2、MNIST 为 0.1t+2、EMNIST 为 0.25t+4；认证公式需要 ∏_{t=tadv+1}^{T}(2Φ(ρt/σt) − 1) 这一跨轮连乘）。干净参考数据：否。额外计算：否。
4. **最终轮被裁剪的全局模型 ClipρT(wT)**。
   - 采集位置：服务器聚合后（server_post_aggregate）/测试前。
   - 粒度：模型级、一次性。认证公式里的最终模型 M(D′)。
5. **M 组加噪模型参数 w̃^k_T = ClipρT(wT) + ϵ^k_T，ϵ^k_T ∼ N(0, σT²I)**。
   - 采集位置：评估时（evaluation）生成，由服务器完成。
   - 粒度：模型级，共 M 份；论文默认 σT=0.01、M=1000（第 6.1 节）。
   - 跨轮历史：否。干净参考数据：否。额外计算：是（M 次噪声采样与 M 份模型副本）。
6. **测试样本 xtest 在 M 个加噪模型下的逐类预测计数 counts 及由此得到的 p̂A、p̂B、pA、pB**。
   - 采集位置：评估时（evaluation）。
   - 粒度：逐样本（每个测试样本需要一轮独立的多数投票统计）。
   - 跨轮历史：否。干净参考数据：否。额外计算：是（每个测试样本需要在 M 个模型上做 M 次前向推理，不需要反向）。论文用错误容忍度 α 把经验频率校正为置信界（第 4.2 节、Algorithm 2），默认 α=0.001。
7. **认证半径公式所需的攻击者参数与 FL 超参数**：攻击者数量 R、缩放因子 γi、毒化比例 qBi/nBi、后门幅度 ∥δi∥、攻击轮 tadv，以及本地迭代 τi、本地学习率 ηi、聚合权重 pi、总轮数 T（Theorem 1、Corollary 1 与式 (2)）。
   - 采集位置：服务器端配置（与第 3 项一起进入 server_post_aggregate 的认证计算）。
   - 粒度：逐攻击者/逐轮。
   - 跨轮历史：是（含 tadv 与 T）。干净参考数据：否。额外计算：否（是公式输入）。论文未说明服务器如何获得 R、γi、qBi/nBi、∥δi∥ 与 tadv 这些属于攻击者的量。
8. **LZ（损失对数据输入的 Lipschitz 梯度常数）与范数上界 ρ**：认证公式的分母需要 LZ；Lemma 1 只对多类逻辑回归给出闭式 LZ = √(2+2ρ+ρ²)，实验中按 ρ_tadv 计算（第 5.1 节、附录 A.1）。论文明确指出对一般神经网络高效计算 LZ 仍是开放问题。

**攻击会留下的可观测量痕迹（论文给出的理论刻画）**：投毒 mini-batch 与良性 mini-batch 的梯度差满足 ∥Bi∥ ≤ (qBi/nBi)·LZ·∥δi∥（Lemma 7）；本地迭代的偏差按 Δ^i_s ≤ 2ηi∥Bi∥s 累积（Lemma 6）；聚合后全局模型的偏差为 ∥w_tadv − w′_tadv∥² = R·Σ_{i=1}^{R}(γi pi Δ^i_τi)²（Lemma 8），因此带缩放因子的恶意更新会在全局模型的 L2 偏移上留下痕迹。实验上，Figure 9(a) 显示 tadv 之后干净全局模型与后门全局模型之间的 L2 距离逐轮下降。

**论文声称能绕过哪些检测**：论文没有声称该攻击能绕过任何具体检测器，也没有做绕过实验。相关工作里提到 Sun et al. (2019) 的"裁剪模型更新范数 + 加高斯噪声"可以缓解基于 model replacement 的后门，但缺乏认证保证（第 2 节）。第 6.2 节报告：在 RFA 鲁棒聚合下攻击者被赋予很低的聚合权重 pi（Figure 6）；CRFL 自身不识别恶意客户端，也没有"绕过/未被绕过"的结论。

## 6. 干预动作

- **训练期（服务器聚合之后、下发之前）**：对聚合后的全局模型参数做 L2 范数裁剪（阈值 ρt），再加逐坐标各向同性高斯噪声（噪声水平 σt）；最后一轮 T 只裁剪不加噪（第 4.1 节、Algorithm 1）。这是对全局模型的"修复/平滑"型干预，不剔除任何客户端、不重新加权、不裁剪单个客户端的更新。
- **测试期**：对最终全局模型做参数平滑，用 M 个加噪模型的多数投票给出预测；当 pA ≤ pB 时输出 ABSTAIN 与半径 0，即拒答而不是修改模型（第 4.2 节、Algorithm 2）。
- **作为评估工具**：CRFL 可以嵌入其他鲁棒聚合规则并给出认证半径，从而评估这些规则的鲁棒性。论文用 RFA（Pillutla et al., 2019）演示：RFA 负责识别离群点并降低恶意更新的聚合权重 pi，CRFL 负责给出认证半径（第 6.2 节、Figure 6）。此时"降权"这个动作来自 RFA，不是 CRFL 本身。
- **动作发生的位置**：全部在服务器端（server）。论文明确写"all of the operations are conducted on the server side"（第 1 节）；客户端侧没有额外操作。

## 7. 实验设置与主要结果

**设置**：模型为多类逻辑回归（单线性层 + softmax + 交叉熵，凸问题）；数据集为 LOAN、MNIST、EMNIST；超参数见 Table 1（第 1 节已列）。客户端本地学习率 ηi=0.001；服务器使用随时间递增的自适应裁剪阈值 ρt（Table 1），训练期噪声固定 σt=0.01（t<T）（附录 A.1）。默认 R=1；认证用 σT=0.01、M=1000、α=0.001（第 6.1 节）。后门模式：MNIST/EMNIST 为像素模式、目标标签"digit 0"；LOAN 为提高两个特征（num_tl_120dpd_2m、num_tl_90g_dpd_24m）的取值、目标标签为"Does not meet the credit policy. Status:Fully Paid"；三个数据集上后门幅度均为 ∥δi∥=0.1（附录 A.1）。数据分布：LOAN 按州划分、非独立同分布（non-i.i.d.）；MNIST 与 EMNIST 按独立同分布（i.i.d.）方式划分给客户端（附录 A.1）。**客户端参与率**：Algorithm 1 每轮遍历 i=1,…,N 全部客户端，论文没有描述部分参与或客户端采样。**轮次 T**：论文未给出统一的默认 T，只写"训练到收敛"；Figure 8 中 LOAN 考察 T=30/50/60/80，EMNIST 考察 T=20/50/70/100/130/150。
**指标**（第 6.1 节）：certified rate at r = (1/m)Σ 1{RADi ≥ r}；certified accuracy at r = (1/m)Σ 1{ci = yi 且 RADi ≥ r}。认证率衡量"可能被后门的分类器"与"干净分类器"预测一致的比例，认证准确率衡量既正确又一致的比例；超过某个临界半径后两者都降为零。

**主要结果**：

- **训练期噪声 σ 的作用**（Figure 2，MNIST/LOAN/EMNIST）：σ 越大，认证率越高、可认证半径越大，但准确率越低，构成可认证性与精度之间的权衡；对比同色实线与虚线可见，测试期参数平滑噪声 σT 对准确率影响不大（第 6.2 节）。
- **攻击强度**：攻击者数量 R 越大、毒化比例 qBi/nBi 越大、缩放因子 γi 越大，可认证半径越小（Figure 3 的 MNIST 毒化比例 5%–50%、LOAN 2.5%–20%；Figure 4 的 γ=10/20/30/50/100；Figure 5 的 R=1–4）。攻击时机 tadv 在攻击后有足够多干净轮次时不敏感（Figure 11 右，使用强攻击 γ=100、R=2，tadv=10/20/40/43/44）。
- **鲁棒聚合**：把 RFA 作为聚合规则时，FedAvg 与 RFA 的横轴量级不同，RFA 下可以认证非常大的半径，原因是攻击者被分配到很低的聚合权重 pi，而 pi 正是式 (2) 中的一项（Figure 5 对比 Figure 6，第 6.2 节）。
- **客户端数量 N**：N 越大，可认证半径越大，因为攻击者的聚合权重 pi 被摊薄，且更多良性更新在训练中稀释后门（Figure 7，MNIST N=20–100、LOAN N=10–50）。
- **训练轮数 T**：T 越大认证准确率越高，但可认证的最大半径不随之增大，原因是标准高斯 CDF Φ(·) 的数值问题使式 (2) 分母中的连乘达不到 0（Figure 8；Figure 9(b) 固定 pA=0.7、pB=0.1 做数值分析）。
- **模型接近度的实证**：单攻击者在 MNIST 上于 tadv=20/40/60 做 model replacement，tadv 之后干净与后门全局模型的 L2 距离逐轮下降，与 Theorem 2 的模型接近度结论一致（Figure 9(a)）。
- **蒙特卡洛估计**：M 越大认证半径越大；认证准确率对错误容忍度 α 不很敏感（Figure 11 左、中；M=100/500/1000/2000/5000，置信度 99%–99.999%）。
- **后门测试集**：在后门测试集上（每个测试样本加后门模式但标签仍正确）结果与干净测试集类似（附录 A.3、Figure 12、Figure 13）。

## 8. 开销

- **论文未报告**训练期与测试期可量化的计算量、通信量或存储量数值（没有 FLOPs、墙钟时间、带宽或内存表格）。
- 有定性描述：训练期服务器每轮多做一次 L2 裁剪和一次逐坐标高斯加噪；客户端侧没有额外操作，论文称所有操作都放在服务器端以减轻客户端负担（第 1 节）。
- 测试期成本有相对比较：论文写"during testing, there are m · M times noise addition on test samples for randomized smoothing, and M times noises addition on trained model for CRFL"（第 4.2 节），即 CRFL 只需对模型加 M 次噪声（与测试集大小 m 无关），而输入平滑需要 m·M 次。每个测试样本仍要在 M 个加噪模型上各做一次前向推理。
- 存储：论文写"Once the M noisy models ... are generated, they are fixed and used for every test sample during test time"，即需要同时持有并复用 M 份加噪模型；论文未给出存储量数值。默认 M=1000（第 6.1 节）。
- 附录导言声称 Appendix A 会给出"runtime of attacks"，但抽取到的正文中没有出现具体的运行时间数值（附录导言）。
- 分析：认证半径计算本身（式 (2) 的连乘与 CDF 计算）的浮点开销论文未讨论。

## 9. 假设、局限与自适应攻击

**方法成立依赖的假设（论文自述）**：

1. Assumption 1：损失函数凸且 β-光滑，并且客户端学习率满足 ηi ≤ 1/β（第 5.1 节）。论文承认这些是分布式 SGD 分析中的常见假设。
2. Assumption 2：损失对数据输入的梯度满足 LZ-Lipschitz；LZ 的闭式只对多类逻辑回归给出（Lemma 1，LZ = √(2+2ρ+ρ²)）。论文明确写"对于一般神经网络，高效计算 Lipschitz 梯度常数（关于数据输入）是一个开放问题，尤其当数据维度很高时"（第 5.1 节）。Lemma 1 的证明条件是 x1 ≠ x2 且 y1 = y2，实验也只针对后门模式 ∥δi∥=∥δix∥、幅度固定为 0.1，标签翻转部分 δy 只在 Assumption 2 中以 z={x,y} 拼接的方式形式化，没有单独数值验证。
3. Assumption 3：整个 FL 系统严格按 Algorithm 1 训练、Algorithm 2 测试。攻击者能做的只有投毒本地数据、多轮本地迭代、按 γi 缩放更新；不能修改裁剪/加噪/平滑流程。
4. 攻击是单轮的：每个攻击者只攻击一次，R 个攻击者在同一轮 tadv 协同攻击，攻击前后都使用干净数据。认证的收缩项 ∏(2Φ(ρt/σt) − 1) 依赖 tadv 之后大量良性客户端继续用干净数据训练来"净化"模型。
5. 后门幅度有界：只有当 ∥δ∥ < RAD 时才给出预测不变的保证；幅度超出半径的攻击不在认证范围内。
6. 服务器必须知道或能上界估计攻击者参数 R、γi、qBi/nBi、∥δi∥、tadv 才能算出 RAD（Theorem 1、式 (2)）。**论文未说明**服务器在不知道谁是攻击者的前提下如何得到这些量。
7. 实验模型是凸的单线性层，数据为 MNIST/EMNIST/LOAN，MNIST 与 EMNIST 的客户端划分是 IID；客户端全部参与、无掉线/采样。
8. 论文自述的局限还包括：式 (2) 分母连乘受数值精度限制，RAD 随 T 增大到某个 ρ/σ 阈值后不再改善（第 5.1、6.2 节）；认证是逐样本的，当 pA ≤ pB 时只能 ABSTAIN。

**自适应攻击**：论文未评估针对 CRFL 的自适应攻击者，也没有让攻击者去优化 γ、后门幅度或攻击轮次来规避认证。实验对 R、γ、毒化比例、tadv 的扫描是攻击强度敏感性分析，不是自适应攻击。第 5.1 节"Defend against Other Potential Attack"只是讨论把分析推广到固定频率攻击（对每个攻击周期重复使用 Theorem 2 与 Theorem 3）和 edge-case/semantic attack（视为整样本操纵）的可能性，未做实验。相关工作还提到很多鲁棒聚合方法假设客户端数据 IID，这在 FL 中通常不成立（第 2 节），而本文实验里 MNIST/EMNIST 恰恰是 IID 划分。

**迁移到联邦大模型 LoRA 微调时可能失效的假设（分析：）**：

- 分析：论文全文未涉及 LoRA、适配器或大模型；把 CRFL 搬到联邦 LoRA 微调时，第一个失效点就是 Assumption 1：Transformer 微调的损失非凸，β-光滑与 η ≤ 1/β 的前提不存在，Theorem 1/2 的推导链（凸性 + 余强制性 + 马尔可夫核收缩）不能直接套用。
- 分析：式 (2) 的分母需要 LZ。论文只对多类逻辑回归给出闭式，且自述一般神经网络是开放问题；在文本模态下"数据样本 z={x,y} 的 L2 距离"与"后门触发词"没有对应关系，∥δi∥ 这个量在 LoRA 场景下没有定义。
- 分析：裁剪与加噪作用在聚合后的参数向量上，测试期的参数平滑是 W ∼ N(w, σT²I) 且需要 M（默认 1000）份模型副本。对 LoRA，可训练参数只是低秩增量（例如 B·A），把 ρt 与 σt 直接用在适配器上需要重新标定（Table 1 的 ρt 调度是为单线性层设计的）；而 M 份 LLM 权重的存储与每个测试样本 M 次前向推理在算力上通常不可接受。
- 分析：单轮攻击 + 攻击后大量良性轮次的假设，与联邦 LoRA 微调常见的"轮数少、通信预算紧、部分客户端参与"不符；如果良性轮次不足，连乘项无法把 KL 距离压到认证阈值以下。
- 分析：论文的威胁模型是恶意客户端投毒本地数据，完全没有建模"恶意适配器发布者"这类参数高效微调供应链威胁；库若面向该场景，需要额外的威胁模型而不是这篇论文的认证。
- 分析：论文中聚合权重 pi、本地迭代 τi、总轮数 T 都按小型凸模型标定；LoRA 聚合通常是加权平均适配器，pi 的取值与"攻击者权重被摊薄"的推论需要重新验证。
- 分析：可以保留的一点是：CRFL 完全在服务器端工作、不访问客户端数据、不需要干净根数据集，这与联邦 LoRA 的隐私约束相容，可作为"只读认证 + 服务器端模型后处理"的模板。

## 10. 对防护库设计的含义

- 分析：采集底座需要在服务器侧提供三类原始数据视图：(a) server_receive 的逐客户端更新（CRFL 本身不用它做检测，但任何聚合插件包括 RFA 都需要它，而且式 (2) 里的 pi 来自聚合权重）；(b) server_post_aggregate 的聚合后全局模型逐轮快照（裁剪、加噪、模型距离监控都只需要这一层）；(c) 逐轮服务器超参数与调度（ρt、σt、σT、T，以及认证所需的 tadv 假设值）。CRFL 不需要客户端原始数据、逐样本损失、隐藏层激活或梯度，这一点是通用的采集边界抽象。
- 分析：认证插件需要一份"攻击参数上界"配置（R、γi、qBi/nBi、∥δi∥、tadv）和一个 LZ 计算器，并且应当做成只读插件：输出每个测试样本的预测标签、认证半径 RAD 或 ABSTAIN，不修改模型，也不需要干净参考数据或根数据集。这是这篇论文特有的需求；通用底座只需保证这些量能作为插件配置传入，而不是硬编码在采集层。
- 分析：干预接口需要一个位于"服务器聚合之后、全局模型下发之前"的模型后处理钩子，允许按参数坐标做 L2 范数裁剪与高斯加噪，并支持"仅最后一轮只裁剪"的轮次条件；插件返回的是修改后的全局参数。通用的是这个边界位置，特有的是"裁剪 + 逐坐标高斯噪声"这一具体形式和平滑推理的配对关系（训练期 σt 与测试期 σT 必须配套）。
- 分析：评估钩子需要支持"对同一个模型生成 M 个加噪副本，在每个副本上对同一样本做前向，再聚合逐类计数"的批量推理模式，并把 M 与 α 暴露为插件参数；对 LLM 而言这意味着 M 份权重或 M 次带噪推理，库应把它建模为显式成本而不是默认开启的路径。
- 分析：跨轮历史视图是硬需求（∏_{t=tadv+1}^{T}(2Φ(ρt/σt) − 1)、tadv、T 以及 ρt 调度），因此底座必须按轮持久化模型摘要与超参数，而不能只保留最后一轮的更新或最终模型。
- 分析：若要迁移到联邦 LoRA 微调，库需要把"参数"抽象成低秩适配器张量并让裁剪/加噪/平滑定义在适配器上；在论文的 LZ 只有逻辑回归闭式、且非凸损失下 Theorem 1 不成立之前，认证半径无法直接迁移，这类插件只能退化为经验性的裁剪-加噪防御，并以"报告认证不适用"而非"给出虚假半径"为默认行为。
