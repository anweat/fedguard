# ax2606.20553：From Efficiency to Leakage - Privacy Backdoor in Federated Language Model Fine-Tuning

## 1. 基本信息

- **场景**：联邦大模型微调（federated fine-tuning of language models）。系统由一个参数服务器（parameter server）与多个客户端组成，客户端在本地用参数高效微调（parameter-efficient fine-tuning, PEFT）方式训练轻量适配器（adapter），服务器用 FedAvg 聚合（第 3 节、第 2.1 节）。论文同时覆盖并行适配器（parallel adapter）与 LoRA 两种微调形态（第 5.5 节、表 5）。安全聚合（secure aggregation）被假设已经部署（第 3 节）。
- **训练阶段**：攻击贯穿联邦微调的单个轮次内的"服务器下发全局模型 → 客户端本地训练 → 服务器聚合"三步，攻击载荷在下发前植入，在第 4.4 节用逐客户端不同的后门使聚合结果近似等于受害者客户端的更新，随后在服务器侧从聚合更新中做闭式反演。图 2 的说明明确写道，因为攻击可以在一轮内完成，所以去掉了表示联邦轮次的上标 r。
- **论文类型**：攻击（数据重建攻击 / 隐私后门，privacy backdoor），附带严格数学分析与一个初步的防御讨论（第 6 节 Discussion、Ethical Considerations 的 Mitigations）。
- **模型与数据规模**：主实验用四个语言模型 BERT、GPT-2、Qwen2-1.5B、Llama3.2-3B，附录 E 扩展到 Qwen2-7B 与 Llama3-8B（表 6）；四个数据集 AGNews、SQuAD、EMRQA-mSQuAD（简称 mSQuAD）、GSM8K，跨数据集迁移实验再引入 MedQuAD。默认联邦设置为 10 个客户端、从训练集中取 8000 个样本（Dtrain）、均匀切分后每客户端 800 个样本，每客户端本地训练 16 步、批大小 50，重建分箱数 m = 2000（第 5.1 节、第 5.2 节）。BERT 是编码器模型，因此不参与 GSM8K 实验（表 2 脚注）。硬件为 AMD EPYC 7643 48 核 CPU 与四张 NVIDIA A100-SXM4-80GB（第 5.1 节）。

## 2. 威胁模型

- **攻击者是谁**：攻击者就是参数服务器 S。原文为"The adversary is the parameter server S."（第 3 节）。客户端被当作诚实的训练者；论文没有讨论恶意客户端、数据提供方或适配器发布者作为攻击者。
- **占比或数量**：默认系统有 10 个客户端（第 5.1 节），攻击者选定其中 1 个作为受害者（"We select one client as the attack victim"），其他客户端收到的是几乎不会被激活的后门变体（第 4.4 节）。服务器只有一个，且本身就是攻击者。
- **能力（能改什么）**：服务器可以恶意初始化嵌入层 PEFT 适配器的线性层与非线性激活函数，把该适配器变成隐私后门（第 3 节 Adversary's Capabilities）；该适配器被实现为挂在嵌入块（embedding block）上的并行适配器（"we assume this PEFT module is implemented as a parallel adapter attached to the embedding block"）。服务器还能针对不同客户端下发不同的后门版本（第 4.4 节：给受害者保留 ∆target_adv，给其他客户端换成偏置为 −[F⁻¹(1−ε), …, F⁻¹(1−ε)] 的版本）。服务器不能看到单个客户端的更新，只能拿到聚合更新（第 3 节）。论文未说明攻击者是否能修改客户端的训练代码、损失函数或优化器。
- **知识（知道什么）**：知道基础模型的原始词嵌入矩阵 W_E（用于主成分分析投影，表 1）；知道模型结构，从而把适配器插在嵌入模块之后、LayerNorm 之前；知道自己植入的初始参数 W2、b2 与超参（隐藏维 h、约简维 ĥ、分箱数 m、最大序列长度 l，表 1）；持有一个公开来源、与目标微调数据集分布相近的辅助数据集 Daux（第 3 节）。论文明确承认现实中攻击者可能只有对目标数据集的泛化认知，因此第 5.4 节专门评估了分布偏移。
- **目标**：隐私窃取，即绕过安全聚合并重建目标客户端微调数据集 Dtarget 的相当大一部分（第 3 节 Adversary's Objectives）。同时要求不造成或几乎不造成性能退化以维持隐蔽性。论文的目标不是无目标破坏、定向后门或越狱/安全对齐破坏。
- **防御者是谁、能看到什么、信任什么**：论文没有给出正式的防御者模型。从第 6 节 Discussion 与 Ethical Considerations 的 Mitigations 可以读出，论文设想的防御者是能访问适配器参数与来源信息的部署方或审计方，可以检查参数级伪影（重复行向量、非标准偏置初始化）并做适配器来源校验与部署前审计。客户端在训练中只能观察到模型性能，而论文声称有攻击与无攻击时性能几乎没有差别（图 11、表 3）。防御者能看到哪些中间量，论文未说明。

## 3. 攻击入口与流程位置

- **入口位置**：攻击载荷在"服务器下发全局模型"这一步进入流程，即全局模型的初始化与分发环节（model distribution）。论文把它归类为 model crafting-based inversion attacks，即参数服务器主动修改模型参数或结构（第 2.2 节）。客户端本地训练过程是被利用的环节，因为后门在本地训练时"记忆"每个样本的梯度；但攻击者并不修改客户端的损失函数、优化器或训练步数，也不修改更新上传前的后处理。
- **具体操作步骤**：
  1. 服务器从一个合法的并行适配器出发构造嵌入层后门 ∆adv：先用投影层 L1 把嵌入降维（`x̂ = (x−µ)Wᵀ`，式 6，取模型原始词嵌入矩阵的主成分），再把 `b×l×ĥ` 重排成 `b×l·ĥ` 送进记忆层 L2（第 4.2 节）。
  2. 记忆层 L2 的每一行权重都设成同一个随机向量 r2，偏置 b2 取辅助分布 ψ 的等概率分位点的负值，`W2 = [r2, r2, …, r2]ᵀ`，`b2 = −[F⁻¹(1/m), F⁻¹(2/m), …, F⁻¹(1)]ᵀ`（式 7），其中 F 是 L2 输入分布 ψ 的累积分布函数，ψ 由 Daux 前向得到。
  3. 每个记忆神经元配一个自定义激活函数 RaLU（Ranged Linear Unit），激活区间上界设为该区间的长度 `F⁻¹((i+1)/n) − F⁻¹(i/n)`（式 8），从而保证每个样本只激活一个神经元，形成"线性激活"而非 ReLU 的"金字塔激活"（图 3）。
  4. 输出层 L3 的行向量全部相同（`W3 = [r3, r3, …, r3]ᵀ`），偏置 b3 全为 0，输出在 token 维与隐藏维上恒定，从而被后续 LayerNorm 完全抵消（第 4.2 节 Output Layer、第 4.5 节）。
  5. 服务器把构造好的适配器随全局模型下发给被选中的客户端；对受害者保留完整的 ∆target_adv，对其他客户端把第二层偏置换成几乎不激活的版本（第 4.4 节）。
  6. 第 4.4 节利用这一点把聚合结果改写成 `θ^(r+1) = θ^r + (1/n)(θ_victim − θ^r)`（式 10），使聚合更新几乎只反映受害者一个客户端的更新，从而在安全聚合仍然生效的前提下恢复对受害者客户端的归因。
  7. 一轮训练结束后，服务器对聚合更新中记忆层 L2 的参数做闭式反演 `x̃ = (W̃2 − W2)/(b̃2 − b2)`（式 9），得到样本的嵌入表示，再确定性地映射回 token 序列（摘要与第 4.3 节；具体的嵌入到文本映射算法在正文中未展开）。
- **进入位置的一句话总结**：攻击内容进入"全局模型下发"，数据泄露发生在"客户端本地训练"，收割发生在"服务器收到聚合更新"。

## 4. 方法原理

- **核心思想**：不直接攻击训练过程，而是把嵌入层的并行适配器改造成一个"隐私后门"，让它在微调过程中把每个训练样本的梯度隔离地记忆到专属神经元里，训练结束后用闭式除法把这些更新反演回样本。
- **闭式反演的基本构件**：对一个线性层 `h = ReLU(Wx + b)`（式 2），当第 i 个神经元被激活时，`∇wi L = (∂L/∂hi)·x`，`∇bi L = ∂L/∂hi`（式 3），因此 `x = ∇wi L / ∇bi L`（式 4）。论文称这是精确解析恢复而不是近似（第 4.1 节）。由此得到 Insight 1：线性层中被激活神经元的梯度可以显式记忆并恢复特定训练样本。
- **分箱思想（Insight 2）**：已有工作固定行向量 wi、变动偏置 bi，用 Daux 造出 m 个"重建箱"，相邻箱相减 `bini = (∇wi L − ∇w(i−1) L)/(∇bi L − ∇b(i−1) L)`（式 5），当本地样本数 d 小于箱数 m 时每个样本可以落在不同箱里被解析恢复。
- **面向 Adam/AdamW 的关键改造（Insight 3）**：Adam/AdamW 是有状态优化器，会跨步纠缠梯度，使单步梯度不可得；唯一可近似反演的是第一步，此时 `Δθ1 = α·m̂1/(√v̂1+ε) ≈ α·sign(g1)`（附录 B 式 15）。因此论文把激活模式从"金字塔激活"改成"线性激活"：用 ψ 的分位点把偏置铺成 m 个等概率区间，再用 RaLU 把每个神经元的激活上界设成区间长度（式 8），使得"每个样本激活唯一神经元、每个神经元在整个训练轨迹中最多被更新一次"，从而单步更新的反演不依赖优化器中间状态（第 4.2 节、图 3）。
- **隐蔽性构造（Insight 4）**：后门输出 o 在 token 维与隐藏维上恒定（写成 z + v，其中 v 是常量特征向量），输入 LayerNorm 后 `µ_ẑ = µ + v`、`σ²_ẑ = σ²`，于是 `LayerNorm(ẑ) = LayerNorm(z)`（式 11、式 12），后续 transformer 块感知不到差别，因此后门被认为对训练性能没有影响（第 4.5 节 Zero Performance Impact）。
- **重建公式（Insight 5 相关）**：设微调后 L2 参数为 W̃2、b̃2，则 `x̃ = (W̃2 − W2)/(b̃2 − b2)`（式 9）。SGD 下每个被激活神经元满足 `W̃2^j − W2^j = −η∇W2^j L` 与 `b̃2^j − b2^j = −η∇b2^j L`，式 9 与式 4 等价，可以精确恢复；Adam/AdamW 下单步更新只能还原为学习率乘符号，因此存在轻微的反演信息损失，式 9 只能近似重建（第 4.3 节、Insight 5）。
- **规模参数**：重建能力由分箱数 m 决定，一个箱对应一个样本；m 可以取几千（论文举例 4096，即语言模型线性层的典型规模），最大 token 长度 l 由攻击者按目标内容设定，实践中可以取几百（论文举例 384）（第 4.5 节 Scalable Reconstruction）。
- 分析：表 1 的"Projection Layer L1"条目把投影写成 `x̂ = L3(x) = (x−µ)Wᵀ`，与第 4.2 节正文中 L1 的记号不一致，疑为笔误；实现时应以正文的 L1 为准。

## 5. 检测或防御所需的数据

### 5.1 攻击自身需要的输入

1. **聚合后的记忆层参数（以及相对下发初值的差分）**
   - 是什么：服务器收到的聚合模型更新中，记忆层 L2 的权重 W̃2 与偏置 b̃2；与服务器自己植入的初值 W2、b2 相减后做逐神经元除法即得样本嵌入。
   - 在哪里采集：服务器收到更新时（server_receive）；在论文场景中聚合已完成，服务器只能拿到 `∑uᵢ = ∑θᵢ`（第 3 节）。
   - 粒度：逐层（L2 的整行/整列），进一步可到逐神经元（每个分箱一个神经元）。
   - 跨轮历史：不需要；论文明确攻击可以在一个轮次内完成（图 2 说明）。跨轮重复只是第 6 节提出的扩大重建量的可选手段。
   - 干净参考数据 / 根数据集：不需要（反演基准 W2、b2 是攻击者自己植入的）。
   - 额外前向或反向计算：不需要。
   - 其他客户端的数据：不需要；第 4.4 节的偏置设计恰好让其他客户端贡献可忽略（式 10）。
2. **下发到客户端的适配器初始状态**
   - 是什么：攻击者写入模型的记忆层初始权重 W2（行向量全为同一随机向量 r2）、偏置 b2（ψ 的分位点）、输出层 W3 与 b3，以及 RaLU 的区间上界与超参 h、ĥ、m、l（表 1）。
   - 在哪里采集：客户端训练前（client_pre_train），也就是服务器下发全局模型的那一刻；服务器侧对应"下发前快照"。
   - 粒度：逐层（逐神经元）。
   - 跨轮历史：不需要。
   - 干净参考数据 / 根数据集：不需要。
   - 额外计算：不需要；其他客户端数据：不需要。
3. **基础模型词嵌入矩阵与由辅助数据得到的偏置分布**
   - 是什么：基础模型的原始词嵌入矩阵 W_E（用于算均值 µ 与投影矩阵 Wᵀ，保留前 ĥ 个主成分），以及把辅助数据集 Daux 前向到 L2 后得到的偏置分布 ψ 及其累积分布函数 F，用来把 b2 铺成等概率区间（式 7）。
   - 在哪里采集：论文中这一步由攻击者在下发模型之前离线完成；在库的钩子语义下最接近"服务器持有全局模型时"（server_post_aggregate），因为它需要基础模型权重。
   - 粒度：模型级（W_E）与逐样本级（Daux 的前向统计）。
   - 跨轮历史：不需要。
   - 干净参考数据 / 根数据集：需要；论文假设攻击者持有一个公开来源、与目标分布相近且与 Dtrain 无重叠的辅助数据集 Daux（第 5.1 节：Daux 取 2000 个测试样本，与 Dtrain 无重叠）。它并不是客户端数据或根数据集。
   - 额外计算：需要（对 W_E 做 PCA，对 Daux 做前向以估计 CDF）。其他客户端数据：不需要。
4. **聚合层面的单客户端主导痕迹**
   - 是什么：由于非受害者客户端几乎不激活，聚合更新近似为 `θ^r + (1/n)(θ_victim − θ^r)`（式 10），即聚合更新几乎只由一个客户端的更新构成；配套可观察量是上一轮全局模型 θ^r，以及（若可得）逐客户端更新或其范数。
   - 在哪里采集：服务器聚合时（server_aggregate）与聚合后（server_post_aggregate）。
   - 粒度：逐客户端（理想情况）或逐轮（只能看到聚合序列时）。
   - 跨轮历史：需要（至少需要上一轮全局模型作为基线）。
   - 干净参考数据：不需要。
   - 额外计算：不需要（做范数/差分统计即可）；其他客户端的数据：若安全聚合严格隐藏单客户端更新则拿不到，只能从聚合序列推断。

### 5.2 攻击留下的可观测量与痕迹

论文第 6 节与 Ethical Considerations 明确指出，NeuroImprint 会留下参数级伪影：记忆层与输出层中重复的行向量（W2、W3 的每一行都是同一个随机向量）、非标准的偏置初始化（b2 是分布分位点的负值、b3 全零），以及一个自行定义的有界线性激活函数 RaLU，这些都偏离典型适配器的初始化与训练模式。分析：此外，输出的跨 token、跨隐藏维恒定值本身也是一个结构性特征，而"下发前恰好插入一个嵌入层并行适配器"这一动作若被记录，也是一个可审计事件。

### 5.3 论文声称能绕过的检测

- **安全聚合**：论文把绕过安全聚合列为主要攻击目标之一，并声称第 4.4 节的设计能恢复对受害者客户端的归因（式 10、第 5.2 节 Client Number Impact 中"robustness in bypassing secure aggregation mechanisms"）。
- **基于效用的检测**：论文用理论证明（式 11、式 12）加实验（图 11 的训练准确率、损失与逐类 ROC，表 3 的准确率/精确率/召回率/F1）声称有攻击与无攻击时模型表现几乎相同，因此客户端观察不到可检测的性能差异。
- 论文没有声称能绕过基于范数的异常检测、鲁棒聚合、参数审计或差分隐私；相反，它在第 6 节承认防御方可能利用参数级伪影检测这种后门。

## 6. 干预动作

- **攻击者一侧的动作**：服务器在下发模型时对非受害者客户端替换第二层偏置为 `b̂2 = −[F⁻¹(1−ε), …, F⁻¹(1−ε)]ᵀ`，其中 ε 是一个小常数，使这些客户端的几乎所有神经元都不被激活、更新可忽略（第 4.4 节）。这一步发生在"全局模型下发"位置。除此之外，攻击者不剔除客户端、不重新加权、不裁剪、不加噪、不过滤样本、不修复或回滚模型；它在拿到聚合更新后只做闭式除法反演，属于"读取并重建"。
- **论文建议的防御动作**：第 6 节 Discussion 的 Potential Defense 建议防御方检查参数级伪影（重复行向量、非标准偏置）来检测可能的握手后门；Ethical Considerations 的 Mitigations 进一步建议做适配器来源校验（adapter provenance checks）与部署前审计（pre-deployment auditing），并建议对后门式构造做实际筛查。检测到之后具体做什么（拒绝该适配器、隔离客户端、回滚本轮、重新初始化或重训），论文未说明。
- 分析：在本文的威胁模型里，服务器本身就是攻击者，因此上述检测/审计动作只有放在服务器之外的位置（客户端侧在下发模型后、本地训练前的校验，或可验证/鲁棒的聚合协议）才可能生效；服务器侧插件只能用于自证合规或第三方审计。

## 7. 实验设置与主要结果

- **模型**：BERT、GPT-2、Qwen2-1.5B、Llama3.2-3B（第 5.1 节），附录 E 追加 Qwen2-7B 与 Llama3-8B（表 6）。
- **数据集**：AGNews、SQuAD（v1.1）、EMRQA-mSQuAD、GSM8K（第 5.1 节），跨数据集迁移用 MedQuAD（第 5.4 节）。各数据集的最大 token 长度分别为 AGNews 128、SQuAD 384、mSQuAD 384、GSM8K 512（表 2）。脚注说明 BERT 因是编码器模型而不参与 GSM8K。
- **客户端数与参与率**：默认 10 个客户端，Dtrain 共 8000 个样本均匀切分，每个客户端 800 个样本；另有客户端数从 5 到 25 的敏感性实验（第 5.1 节、图 10）。论文未报告采样参与率这一概念。
- **轮次**：攻击在单个轮次内完成；隐蔽性验证跑 20 轮联邦训练（第 5.3 节）。
- **恶意比例**：攻击者是唯一的参数服务器；客户端默认全部诚实，其中 1 个是受害者（第 5.1 节）。
- **非独立同分布**：用 Dirichlet 分布划分，α 取 {0.1, 0.3, 0.5, 0.7, 0.9}，α 越小越倾斜（第 5.2 节、图 9）；跨数据集迁移构成另一种分布偏移（第 5.4 节、表 4）。
- **指标**：重建率（Rate）与语义相似度（Sim.，用 Sentence-Transformer 计算原样本与重建样本的句嵌入余弦相似度，式 13），相似度同时报告标准差。
- **关键结果**：
  - 总体重建率 59% 到 79%（摘要与第 1 节），第 5.2 节表述为"能重建相当大比例（>55%）的样本且语义保真度高"。表 2 中 BERT/AGNews/SGD 为 0.774|0.994±0.028，BERT/SQuAD/AdamW 为 0.772|0.714±0.097，GPT-2/GSM8K/AdamW 为 0.654|0.524±0.116（相似度最低者）。
  - AdamW 下的语义相似度一致低于 SGD，与 Insight 5 一致；重建率在两种优化器之间没有一致优势（第 5.2 节、图 6）。
  - 分箱数 m 从 1000 增到 3000 时重建率上升、相似度稳定（图 7，GPT-2/AGNews）；目标数据规模 d 从 400 增到 1200（m 固定为 2000）时重建率下降、相似度稳定（图 8）；结论是重建效果由 m 与 d 的比值决定，经验上 `m/d > 2` 时表现良好（第 5.2 节）。
  - 非独立同分布程度变化只轻微影响重建率，相似度稳定（图 9）；客户端数从 5 到 25 变化时重建率与相似度都高度稳定（图 10）。
  - 隐蔽性：20 轮训练中有无攻击的准确率与损失曲线几乎重合，逐类 ROC 的 AUC 在有无攻击时完全相同（World 0.975、Sports 0.995、Business 0.937、Tech 0.972，图 11）；表 3 中非独立同分布 0.9 时无攻击准确率 0.8530、有攻击 0.8420，0.1 时无攻击 0.8360、有攻击 0.8430。
  - 跨数据集迁移：EMRQA→MedQuAD 的 AdamW 为 0.504|0.713±0.147，SQuAD→EMRQA 的 AdamW 为 0.649|0.808±0.076，最差一档是 SQuAD→MedQuAD 的 SGD，重建率仅 0.245、相似度 0.969±0.118（表 4）；辅助数据越贴近目标域，迁移越好。
  - LoRA 设置（rank 为 8、缩放因子 32、dropout 0.1，作用于 transformer 块内的注意力与投影层；嵌入块仍使用并行适配器）：效果与表 2 基本一致，部分设置更好，例如 Llama3-3B/AGNews/AdamW 为 0.759|0.918±0.071，Llama3-3B/GSM8K/AdamW 为 0.787|0.864±0.065（第 5.5 节、表 5）。
  - 更大模型：Qwen2-7B/AGNews/SGD 为 0.748|0.998±0.030，Llama3-8B/AGNews/SGD 为 0.723|1.000±0.000，Llama3-8B/GSM8K/AdamW 为 0.804|0.893±0.060（表 6）。
  - 可选的 LLM 改写后处理（用 ChatGPT-5 对 AdamW 下的重建文本做润色，附录 F、表 7）：Qwen2-1.5B/mSQuAD/AdamW 从 0.736|0.767±0.077 提升到 0.736|0.851±0.066，GPT-2/GSM8K 从 0.654|0.524±0.116 变为 0.635|0.522±0.108，即对 GPT-2 几乎没有收益。

## 8. 开销

- **存储/显存**：论文报告"重建 2000 个样本在 Llama-3.2 上大约需要 200MB，不到模型大小的 3%"（第 6 节），并说明记忆开销随分箱数 m 近似线性增长，记忆层不能无限扩展；在固定内存预算下可以只使用 ψ 的一个子集来构造分箱，或跨多个联邦轮次重复攻击以累计恢复更多样本。
- **计算**：论文说明投影层把维度从 h 降到 ĥ 是为了降低计算开销，BERT 上 h = 768、ĥ = 64（第 4.2 节），但没有给出可比的训练时延、FLOPs 或反演耗时的定量数字。
- **通信**：论文未报告通信开销的定量数据；从设计上看，后门是随全局模型下发的适配器的一部分，因此一次攻击的额外通信量并未被单独测量（分析）。
- 结论：论文报告了存储/内存开销，未报告计算与通信开销的量化结果。

## 9. 假设、局限与自适应攻击

- **成立所依赖的假设**：
  1. 参数服务器是恶意方，且能自由决定下发给每个客户端的嵌入层并行适配器的初始化（权重与非线性激活函数）；
  2. 系统已经部署安全聚合，服务器只能看到聚合后的模型更新；
  3. 客户端诚实训练、不会校验下发适配器的初始化，且损失梯度会正常回传到嵌入层后门；
  4. 宿主模型在嵌入块之后紧跟 LayerNorm，使得跨 token 与隐藏维恒定的后门输出被归一化完全抵消；
  5. 攻击者持有公开来源、与目标分布相近的辅助数据集 Daux，用于估计偏置分布 ψ 与分位点；
  6. 单个联邦轮次内每个记忆神经元最多被一个样本激活一次（需要本地样本数 d 不超过分箱数 m，经验上要求 m/d > 2）；
  7. 嵌入层后门必须用满秩并行适配器实现；LoRA 的低秩近似不在后门本身使用；
  8. 攻击在一个轮次内完成，跨轮重复只是扩大重建量的可选手段。
- **论文自述的局限**：Adam/AdamW 下只能近似重建，存在反演信息损失（第 4.3 节、Insight 5）；记忆层不能无限扩展，存在可扩展性与内存空间的权衡（第 6 节）；重建率随目标数据规模增大而下降（图 8）；辅助数据与目标数据存在分布偏移时效果下降（表 4，最差仅 0.245）；LoRA 不适用于后门自身，尤其是关键的记忆层，因为低秩近似会破坏所存梯度的保真度（第 4.5 节）；攻击会留下参数级伪影（第 6 节、Ethical Considerations）。
- **自适应攻击者**：论文没有评估自适应攻击者。第 6 节只是定性地说"即使攻击者可以执行自适应攻击来规避检测，这也会对设计构成约束并导致攻击效果下降"，没有给出实验或定量结果。
- **迁移到联邦 LoRA 微调时可能失效的假设（分析：）**：
  - 论文已经在 LoRA 设置下做过实验（表 5），但它明确要求嵌入块仍然使用并行适配器（"the embedding block is still using a parallel adapter to enable the attack"）。如果目标系统只允许客户端接收与上传 LoRA 的 A/B 低秩增量、并且对下发模块做白名单校验，那么本文的攻击载荷无处安放；但只要系统允许下发任意模块（嵌入层适配器、prompt 前缀、modules_to_save 等），攻击面就存在。因此库的采集必须覆盖"下发的完整模块集合与结构"，而不只是 LoRA 增量。
  - 论文的隐蔽性证明建立在 LayerNorm 的减均值、除标准差性质上（式 11、式 12），而实验中的效用对比只在 GPT-2/AGNews 上给出（图 11、表 3）。若宿主模型在嵌入后使用不做均值中心化的归一化，该抵消推导不再直接成立；这一风险论文没有讨论，需要在新宿主上重新验证。
  - 论文假设一轮内每个记忆神经元只被激活一次，对应"每客户端 800 样本、16 步、批 50"这种恰好一个 epoch 的配置。真实联邦 LoRA 训练常有多轮、多 epoch、动态采样与更大的本地数据，一次激活的前提会变弱；多 epoch 下同一样本可能多次更新同一神经元，Adam 的状态历史重新进入问题。论文没有分析多 epoch 情形。
  - 论文依赖 Daux 与目标分布相近。实践中的联邦 LoRA 客户端数据通常高度领域化且私有，公开辅助数据更难匹配，攻击会明显衰减（表 4 已给出衰减幅度）。
  - 论文的攻击之所以在安全聚合下仍然有效，是因为它让其他客户端几乎不更新，使聚合结果被单个客户端主导。若聚合侧保留逐客户端更新的异常统计或采用鲁棒聚合，这一痕迹会很显眼；但本文威胁模型里服务器就是攻击者，所以这类服务器侧防御在该模型下不成立，真正的位置只能是客户端侧校验或可验证/鲁棒的聚合协议。论文没有评估鲁棒聚合。
  - 论文正文没有给出把嵌入还原成 token 序列的确定性映射细节，也没有给出 LoRA 场景下反向传播到后门的梯度尺度分析；要在库中复现该攻击或编写对应检测器，这两部分需要自行补足。

## 10. 对防护库设计的含义

1. **分析：**采集底座需要在"服务器下发模型之前"对完整模型状态做快照，而不只是记录 LoRA 增量。本文的攻击载荷是一个挂在嵌入块之后的并行适配器，含自定义激活函数与特定超参（ĥ、m、l）。因此客户端钩子应能拿到下发模块的完整 `state_dict`、模块连接图与激活函数配置，并对快照做哈希，供后续差分与来源追溯使用；这是通用能力，但"嵌入块适配器"这一采集位置是本文特有的。
2. **分析：**采集底座需要在"服务器收到聚合更新时"按逐层、逐神经元粒度保存聚合后的参数，并能与步骤 1 的下发快照做差分（对应式 9 的 W̃2 − W2 与 b̃2 − b2）。粒度要求到神经元行，否则无法判断"哪些神经元被激活、激活是否呈等概率分位点分布"。依赖上一轮基线的差分属于跨轮历史需求，应在服务器聚合钩子上提供。
3. **分析：**需要一个服务器侧（或第三方审计侧）的"适配器静态审计"插件接口，输入是模块参数与激活函数类型，检查项包括重复行向量、常量或零偏置、按分位点等间距排列的偏置数组、非标准的有界线性激活函数。这对应论文第 6 节建议的参数级伪影检测，是本论文特有的检测逻辑，但接口本身是通用的插件挂载点。
4. **分析：**若要在聚合层面检测"聚合更新被单个客户端主导"这一痕迹（式 10），库需要提供逐客户端更新的范数或差分统计；但在安全聚合下这些数据不可得，此时退化为对聚合序列与上一轮全局模型的时序异常检测。这个需求是通用的，而本文的攻击正是把它当作必须依赖的观测缺口。
5. **分析：**若插件需要按分布或分位点比对偏置向量，库应提供"可插拔的干净参考数据集 + 一次性前向统计"的能力（对应论文里的 Daux 与 ψ）。这属于通用的可选能力，但需要明确定义参考数据的来源、覆盖范围与不重叠约束，因为论文明确假设 Daux 与训练集无重叠。
6. **分析：**干预接口方面，论文只给出了"检测可疑构造 + 适配器来源校验 + 部署前审计"的方向，没有定义检测后的动作。库应把"拒绝或隔离可疑适配器、阻止本轮下发"作为服务器侧的统一动作，但必须意识到：在本文威胁模型下服务器就是攻击者，服务器侧插件无法防住它，真正的落点只能是客户端侧在下发模型到达后、开始本地训练前的校验钩子，或者可验证聚合协议。这一点决定了该防御插件的挂载位置，属于本文特有的约束。另外，论文未说明嵌入到 token 的还原方法，库若要内置"重建验证器"需自行实现这部分。
