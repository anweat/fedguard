# ax1811.00741：Stronger Data Poisoning Attacks Break Data Sanitization Defenses

## 1. 基本信息

**场景。** 这篇论文研究的是**集中式（centralized）传统机器学习训练**中的数据投毒（data poisoning），不是联邦学习，也不是大模型训练。论文全文没有出现联邦学习、客户端、聚合服务器、LoRA 或大语言模型的设定。它的实验对象是线性分类器（linear classifier），具体为线性支持向量机（support vector machine, SVM）与逻辑回归（logistic regression），训练数据是集中持有的（论文由单一防御者在合并后的训练集 D = Dc ∪ Dp 上训练，见第 2.2 节）。论文类型是**攻击论文**，即提出三种新的投毒攻击以击穿数据清洗（data sanitization）防御；它并不提出新的防御方法，而是把五种既有的清洗防御当作被测对象。论文发表于 Machine Learning 2021，最早于 2018 年出现在 arXiv（第 1 页脚注）。

**训练阶段。** 攻击发生在**训练数据收集与准备阶段**，即在模型训练开始之前把毒化样本注入训练集。论文在第 7.1 节把数据投毒明确归类为“train-time attacks”。清洗防御同样发生在训练之前的训练集组装阶段。

**模型与数据规模。** 见论文表 1（Table 1）：Enron 垃圾邮件二分类数据集，训练样本数 n = 4137，测试样本数 ntest = 1035，特征维度 d = 5116，干净数据上的基准错误率 2.9%（正则化系数 λ = 0.09），输入约束为非负整数；IMDB 情感二分类数据集，n = 25000，ntest = 25000，d = 89527，基准错误率 11.9%（λ = 0.01），输入约束为非负整数；MNIST 十分类，n = 60000，ntest = 10000，d = 784，基准错误率 7.5%，输入约束为 [0, 1]；MNIST-1-7 二分类，n = 13007，ntest = 2163，d = 784，基准错误率 0.7%（λ = 0.01）；Dogfish 二分类，n = 1800，ntest = 600，d = 2048，基准错误率 1.3%（λ = 1.10）。第 5.1 节正文另称 Enron 的基准错误率为 3.0%，与表 1 的 2.9% 略有出入，摘要在描述攻击效果时也从 3% 起算。

## 2. 威胁模型

**攻击者是谁。** 论文没有客户端或服务器的角色划分，攻击者是能够**向集中式训练集注入新样本的数据提供方或外部攻击者**。第 1 节对这类攻击者的现实刻画是“通过攻击数据收集过程，这可能和创建一个新用户账户一样容易，对手就能向系统中注入恶意数据”。

**占比或数量。** 攻击者注入的毒化点数量为 |Dp| = ϵ|Dc|，即干净样本数的一个比例（第 2.1 节）。实验统一取 ϵ = 3%（第 5.2 节，表 2）。论文第 1 节明确说明全文只考虑注入“3% 或更少”的小比例毒化数据，高 ϵ 设定不是本文重点（第 5.4 节脚注 3 提到 ϵ = 0.3 的设定比本文考虑的大十倍）。

**能力。** 攻击者同时控制毒化点的**标签 ỹ 和输入特征 x̃**（第 7.1 节明确写“本文提出的攻击同时控制毒化点的标签和输入特征”）。攻击者不能修改干净数据 Dc 本身，只能新增点；毒化点必须落在可行集 Fβ 内，否则会被清洗掉。论文明确说明这些攻击**不是干净标签攻击（clean-label attack）**，毒化点在人类专家看来不一定标注正确。

**知识。** 第 2.1 节给出攻击者的信息优势：攻击者能够观察到测试集 Dtest 以及干净训练集 Dc，并且知道防御者的训练流程；论文把“攻击者知道测试集”解释为攻击者往往先确定要打错哪一批样本，因此本来就能看到它们。防御者则不知道攻击者的目标，通常也拿不到 Dtest。第 5.2 节的脚注 2 补充：本文框架假设攻击者事先知道防御者的正则化系数 λ，这对防御者是一个潜在劣势；第 6 节专门研究了攻击者信息不完整时的可迁移性。

**目标。** 攻击目标是**无目标破坏（indiscriminate attack，亦称拒绝服务式破坏）**：测试数据 Dtest 与干净训练数据 Dc 同分布，攻击者设法抬高防御者模型的平均测试错误率（第 2.1 节、第 7.1 节）。第 7.1 节把有目标攻击（targeted attack）和后门攻击（backdoor attack）放在相关工作里讨论，并指出本文的影响函数攻击与 KKT 攻击不依赖测试集性质，因此可以不加修改地用于有目标设定，而 min-max 攻击只适用于无目标设定；论文没有实际做后门实验。

**防御者是谁、能看到什么、信任什么。** 防御者持有合并后的训练集 D = Dc ∪ Dp，先用异常检测器给每个点打异常分数并剔除可疑点，再在剩下的数据 Dsan 上训练（第 2.2 节）。防御者能看到每个训练点的特征与标签，能自己训练一个未清洗的参考模型（loss 防御），能做矩阵分解（SVD 防御），能计算样本间距离（k-NN 防御），也能计算类质心（L2 与 slab 防御）。防御者不知道哪些点真正是毒化点，也不掌握干净的参考数据集；第 7.2 节把“拥有被标注的异常样本”“拥有可信数据子集 T”“拥有训练点加入时间等元数据”列为文献中更强的防御设定，并说明本文考虑的是不具备这些额外信息的防御者。

## 3. 攻击入口与流程位置

**入口位置：训练数据准备（数据入池）阶段。** 攻击内容不进入本地训练的损失函数或优化器，不涉及更新上传后的缩放、投影或拼装，不涉及服务器聚合，也不涉及全局模型下发或评估部署。攻击者所做的全部事情是：在防御者开始清洗与训练之前，向集中式训练集追加 ϵn 个自己构造的样本及其标签。

**具体操作步骤（第 3 节至第 4 节）。**

第一步，攻击者确定要绕过的防御集合，并据此写出可行集 Fβ。L2 与 slab 防御的可行集由干净数据上的类质心决定，可以直接写死；loss 防御的可行集依赖防御者最终学到的参数，攻击者改用诱饵参数（decoy parameters）θdecoy 把这条约束也近似固定下来；k-NN 与 SVD 防御靠“集中化”绕过，不写成显式约束。

第二步，攻击者用算法 3（Algorithm 3）生成诱饵参数：先在干净数据上训练得到 θc，从测试集里挑出在 θc 下损失超过阈值 γ 的样本，把它们的标签翻转后复制 r 份得到 Dflip，在 Ddecoy = Dc ∪ Dflip 上重新训练得到 θdecoy；通过扫描 γ 与 r 生成多个候选诱饵参数，逐个尝试并保留测试错误率最高的那个。

第三步，攻击者在固定可行集 Fβ 下求解约束优化问题，即最大化防御者学到的参数在测试集上的损失，约束为毒化点数量等于 ϵ|Dc| 且每个毒化点都落在 Fβ 内（公式 (4)）。三种攻击给出三种近似求解方式，分别是影响攻击（第 4.1 节）、KKT 攻击（第 4.2 节）与 min-max 攻击（第 4.3 节）。

第四步，攻击者用定理 1 把毒化点压缩到每类一个（二分类共两个）不同位置，并按权重放置分数份拷贝。

第五步，对于特征必须是非负整数或 [0, 1] 区间的数据集，攻击者先解出连续值的毒化点，再做随机舍入（randomized rounding）得到合法输入，并配合重复点启发式（把舍入后的点重复 r 次，实验中 r = 2 或 3）与针对 L2 约束的线性规划松弛（公式 (5) 至公式 (8)）保持集中性与可行性。

第六步，防御者按第 2.2 节的流程拟合异常检测器 β = B(Dc ∪ Dp)，剔除落在可行集外的点，再在 Dsan 上训练；攻击者的目标是让这一流程最终学到的参数仍然具有高测试错误率。算法 1（Algorithm 1）还给出一个可选迭代版本：在“固定 β 求解 Dp”和“用新的 Dp 重新拟合 β”之间交替，直到 Dp 收敛。

## 4. 方法原理

**核心思想。** 论文摘要把攻击归纳为两个想法：一是协调毒化点，让它们彼此靠近（集中化攻击）；二是把攻击写成带约束的优化问题，约束条件专门设计为保证毒化点能躲过异常检测。围绕第二个想法，论文指出真正要解的是一个双层问题（bilevel problem）：外层是攻击者选择毒化点，内层是防御者在合并数据上求最小训练损失；该问题非凸且难以精确求解，因此论文给出三种近似。

**通用的形式化（第 2.2 节、第 3.2 节）。** 防御被抽象为一个由数据集拟合出的打分函数 sβ(x, y) 与阈值 τy，可行集 Fβ 收集分数低于阈值的点，防御者在 Dsan = D ∩ Fβ 上最小化正则化训练损失，即 (λ/2)‖θ‖² 加上 Dsan 上的平均替代损失（公式 (2)）。攻击者的约束优化问题为公式 (3) 与公式 (4)：最大化测试损失 L(θ̂; Dtest)，约束毒化点数量为 ϵ|Dc| 且 Dp 含于 Fβ。为求解，论文做了三个近似：假设防御者不会误删干净点；把 β 固定在干净数据上（β = B(Dc)），从而切断可行集对 Dp 的依赖；用凸替代损失替换 0-1 测试错误率。

**集中化与定理 1。** 定理 1（Theorem 1，正文与附录 A）证明：若防御者先剔除可行集 F 之外的点，再最小化平均正则化训练损失，且每一类的可行集 Fy 是凸集，那么任何用 ñ 个毒化点能达到的参数 θ̂，都可以用至多 ñ 个点、但只包含两个不同位置（每类一个）的毒化点达到；该结论对二分类 SVM 与逻辑回归成立，也可推广到任意形如 ℓ(θ; x, y) = c(−yθᵀx) 的间隔型损失，只要 c 凸、单调递增、二阶可导且二阶与一阶导数之比 c″/c′ 单调不增。附录 A 的命题 10 进一步给出 k 分类 SVM 需要 k(k−1) 个不同位置。第 3.1 节解释了集中化为什么有效：对 k-NN 防御，几个毒化点彼此靠近时它们到最近邻的距离自然很小；对 SVD 防御，低秩表示更容易把毒化点包含进去；对 loss 防御，集中在一起的毒化点让模型有更强的动机去拟合它们。

**三种攻击。**

影响攻击（第 4.1 节）：直接对毒化点的特征做投影梯度上升。梯度由链式法则给出，测试损失对参数的梯度是测试集上的平均梯度 g（公式 (9)），参数对毒化点的导数用影响函数近似，即负的 Hessian 逆乘以二阶交叉导数（公式 (10)），Hessian 为 λI 加上训练集上的二阶导数平均（公式 (11)）。每步更新后把毒化点投影回可行集。改进之处是加入线性规划松弛与集中化，使每轮只需计算两个点的梯度与投影。附录 B.1 说明为计算梯度把 hinge 损失替换成光滑版本，并用快速 Hessian 向量积与共轭梯度求解。

KKT 攻击（第 4.2 节）：先按算法 3 找诱饵参数 θdecoy，再把“防御者会学到 θdecoy”这一内层最优性条件写成等价的 KKT 一阶条件，即干净点的参数梯度之和加上毒化点的参数梯度之和等于零（公式 (13)）；把该等式约束移到目标里得到范数最小化问题（公式 (15)），再用定理 1 将其压缩为关于两个点位置 x̃+、x̃− 与两类配额 ϵ+、ϵ− 的问题（公式 (16)）；在 hinge 损失加 L2 正则化下进一步写为公式 (17)，并网格搜索 ϵ+ 与 ϵ−（算法 4）。对 loss 防御，攻击者用诱饵参数把约束 ℓ(θdecoy; x̃, ỹ) < τỹ 加进可行集。

min-max 攻击（第 4.3 节）：改进自 Steinhardt 等人的 min-max-basic 攻击。基本版把测试损失换成训练损失（公式 (18)），利用损失非负性得到上界（公式 (19)），从而把双层问题化成鞍点问题（公式 (20)）并交换最小与最大，得到可直接用次梯度下降求解的形式（公式 (21)）；算法 5 每轮在可行集内找出当前参数下损失最大的点并加入攻击集。论文的改进是用诱饵参数给可行集增加约束 ℓ(θdecoy; x, y) ≤ τ（公式 (22)），使毒化点在诱饵参数下损失很低，从而既不被 loss 防御过滤，又能把学到的参数拉向诱饵参数。min-max 攻击不需网格搜索就能自动处理类别配比，也不要求可行集凸，但只在无目标设定下成立。

## 5. 检测或防御所需的数据

本节先列出论文中五种清洗防御各自需要的输入（它们就是检测插件可能采用的数据视图），再列出攻击会留下的可观测量。

**（一）防御所需的数据。**

1. **逐样本的特征向量与标签。** 这是五种防御的共同底座，包含全部干净点与毒化点。采集位置是训练集组装完成、异常检测器拟合之前，也就是本文语境下的训练前数据准备环节；在联邦 LoRA 的类比下对应客户端训练前。粒度是逐样本，不需要跨轮历史，不需要干净参考数据集，不需要额外计算。

2. **每一类的特征质心 μy = E_D[x|y]。** 用于 L2 防御（分数为样本到本类质心的 L2 距离）和 slab 防御（分数为样本在两类质心连线方向上的投影偏离量）。采集位置是在合并训练集上做一次一阶统计，粒度是每个类别一个全局向量（在库的语境下可按轮重新估计），不需要逐样本损失，也不需要额外的前向或反向计算。算法 1 的迭代版本会在每一轮用新的毒化点重新拟合这两个防御的 β，因此若采用迭代版本则需要保留轮次状态。

3. **一个在未清洗的完整数据 D 上训练出来的参考模型及其逐样本损失 ℓβ(x, y)。** 这是 loss 防御的全部输入（β 为该模型参数，分数为样本在该模型下的损失）。采集位置是先在全量数据上训练一次，再对每个样本做一次前向计算得到损失值；粒度是逐样本，但模型是全数据集级别的，因此需要额外的训练与前向计算。第 2.2 节说明这一防御与回归场景中提出的 trimmed loss 防御类似，对线性模型而言它和 slab 防御相近，只是相关方向改由损失函数学出而不是固定为类心连线方向。

4. **数据矩阵 X 的前 k 个右奇异向量与每个样本在正交补上的残差范数。** 这是 SVD 防御的输入，分数为 ‖(I − ββᵀ)x‖₂；实验选取使归一化 Frobenius 近似误差小于 0.05 的最小 k（第 2.2 节）。采集位置是在合并训练集上做一次奇异值分解，粒度是逐样本残差加一个数据集级别的子空间，需要额外计算。

5. **每个样本到其第 k 近邻的距离。** 这是 k-NN 防御的输入，β 就是整个数据集 Dc ∪ Dp 本身，实验取 k = 5（第 2.2 节）。粒度是逐样本，但必须能看到全部样本才能计算，因此需要跨客户端或全量的样本视图以及额外的近邻搜索计算。

6. **输入域约束。** 第 2.2 节指出可行集 Fβ 同时编码防御与数据集的输入约束：Enron 与 IMDB 要求非负整数，MNIST 与 MNIST-1-7 要求 [0, 1] 区间，Dogfish 无约束（表 1）。这些约束在清洗时会被一并用于剔除非法点。

**（二）攻击留下的可观测量与论文声称绕过的检测。**

论文声称三种攻击能同时躲过上述五类异常检测器（第 1 节、第 5.2 节）。具体痕迹与规避手段如下：

- **近似重复点与高密度聚集。** 定理 1 与第 3.1 节意味着攻击会把大量毒化点压缩到每类一个位置（二分类共两个），或经随机舍入后压缩到少数几个位置。第 3.1 节承认这类攻击“可以被一个剔除重复点的防御者轻易击败”，但攻击者可以对毒化点加入少量随机噪声，使其在被舍入后仍然保持集中性而不完全重复；第 3.3 节的重复点启发式就是对这一问题的工程处理。因此可观测的痕迹是“极高密度的近邻簇”，而论文的对策是模糊化。
- **距离类异常分数。** 对 k-NN 防御，集中化使毒化点到最近邻的距离很小，论文称这是“平凡的成立”（第 3.1 节）。对 L2 与 slab 防御，攻击在求解时直接把毒化点投影到这两个防御的可行集内，因而在干净数据拟合出的阈值下不会被剔除。
- **低秩结构残差。** 第 3.1 节指出，毒化点集中时，数据的低秩表示更可能把毒化点包含进来，从而减小它们的投影外分量，使 SVD 防御失效。
- **逐样本损失。** 论文第 1 节把“毒化点不必在毒化后的模型下有高损失”列为主要发现之一；KKT 攻击与 min-max 攻击都用诱饵参数把毒化点的损失压低（第 4.2.2 节与第 4.3.2 节），从而绕过 loss 防御。
- **论文没有报告任何检测器能识别出这些毒化点。** 第 6 节的迁移实验表明，在攻击者不知道测试集、不知道正则化强度、防御者改用随机梯度下降或改用 logistic 损失时，三种攻击仍然有效，唯一的例外是 loss 防御在上述分布偏移下会显著削弱攻击（第 6.3 节，图 11）。

## 6. 干预动作

这篇论文本身是攻击论文，因此“干预动作”指的是它作为攻击对象的那套防御流程。防御者的干预是**样本过滤（filter_samples）**：先按 B(D) 拟合异常检测器参数，构造可行集 Fβ，把分数超过阈值 τy 的训练点直接从数据集中**剔除**，然后在剩余数据 Dsan 上重新训练（第 2.2 节）。第 5.2 节给出实验中的阈值设定方式：让防御者从每个类别中剔除 p = 5% 的训练数据。论文没有采用重新加权、梯度裁剪、加噪、模型修复或回滚等干预，也没有任何“只报告不处理”的设定。

动作发生的位置是**模型训练之前的集中式训练集组装阶段**，即清洗与训练在同一个数据持有方内部顺序完成。论文没有客户端与服务器的区分，因此不存在“在服务器聚合时干预”或“在下发时干预”的说法。第 7.2 节与第 8 节讨论了若干更强的防御方向，但都停留在相关工作或展望层面，没有实现与评估：使用被标注的正常与异常样本训练监督式异常检测器，使用训练点加入时间等元数据（Cretu 等人的做法），使用可信数据子集做 RONI 式拒绝或只在可信子集上计算近邻距离，在数据的不同子集上训练多个模型，以及迭代地剔除梯度异常的点并重新拟合（Diakonikolas 等人的方法，被视为 loss 防御的更复杂版本）。第 8 节还提出用有界但非凸的替代损失替换 0-1 损失的无界凸替代，并指出这可能带来把学习器推向坏局部极小值的新攻击面。

## 7. 实验设置与主要结果

**模型与训练。** 二分类任务使用 hinge 损失加 L2 正则化的 SVM，正则化系数在干净数据上通过交叉验证选定（第 5.2 节）；多分类任务使用 Crammer 与 Singer 的多分类 SVM 形式（第 5.2 节、表 1），在 MNIST 上用 AdaGrad 训练，批量大小为 20，步长为 0.02，训练数据遍历 3 遍（附录 B.3）。

**数据集与规模。** 见第 1 节引用的表 1。攻击实验以 Enron 与 IMDB 为主，MNIST 用于多分类演示，MNIST-1-7 与 Dogfish 放在附录 C。

**攻击预算与清洗强度。** ϵ = 3% 的毒化数据；防御者从每个类别剔除 p = 5% 的训练数据（第 5.2 节）。因为攻击者事先不知道防御者会部署哪一种防御，论文对每个攻击分别用五种防御各自评估一次，取“在所有防御上的最小测试错误率增量”作为该攻击的得分（第 5.2 节）。

**是否有客户端、参与率、数据异构性。** 论文未说明——这套实验是集中式训练，不存在客户端数量、参与率或非独立同分布（non-IID）数据的设定，论文全文没有讨论这些概念。

**关键结果。**

- Enron 数据集在 ϵ = 3% 时：影响攻击 18.3%，KKT 攻击 22.5%，min-max 攻击 23.7%（表 2）。摘要给出的口径是 Enron 从 3% 提升到 24%，IMDB 从 12% 提升到 29%（摘要）。附录 C 与图 12 说影响攻击把 Enron 从 3% 推到 23%。
- 图 3 显示在 Enron 上 KKT 与 min-max 的测试错误率略高于影响攻击，并且计算上更高效，因而能跑在更大更高维的 IMDB 上。
- 攻击耗时：影响攻击用了 286 分钟才达到 17% 错误率，KKT 攻击只用 27 秒，min-max 攻击处理第一个诱饵参数用了 28 分钟并得到 23.0% 错误率（第 5.3 节、图 4）。
- 迭代优化：在 Enron 上迭代更新可行集只比固定可行集提高几个百分点的测试错误率（第 5.4 节、图 5）。在 MNIST-1-7 上以 ϵ = 0.3 运行时，不迭代的影响攻击只提高 1.1% 的测试错误率，迭代版本提高到 7.5%，而 Steinhardt 等人用专门的半定规划在同一设定下达到 39% 的提升（第 5.4 节及其脚注 3）。
- 消融实验：去掉线性规划松弛使 Enron 测试错误率下降几个百分点，再去掉集中化后下降更明显，影响攻击的基础版在 loss 与 SVD 防御下无法把测试错误率提高到 11% 以上（第 5.5 节、图 6）。min-max 基础版被 loss 防御击败，测试错误率只有 10.0%（第 5.6 节、图 7）。
- 多分类：在十分类 MNIST 上以 ϵ = 3% 运行 min-max 攻击，面对 L2 防御得到 15.2% 的测试错误率，面对 loss 防御得到 13.7%（第 5.7 节、图 8）。
- 迁移性（第 6 节、图 9）：攻击者不知道测试集、改用训练集优化时，影响攻击的测试错误率从 18.3% 降到 10.9%，KKT 从 22.6% 降到 16.5%，min-max 从 23.7% 降到 19.0%。
- 正则化（第 6.2 节、图 10）：把防御者的 λ 从 0.009 变到 0.9 而攻击者的 λ 固定为 0.09；面对 L2 防御，影响攻击在 λ = 0.009 时测试错误率低于 10%，min-max 攻击在 λ = 0.009 时仍有 22%。论文由此得出结论：增大正则化反而可能让防御者更脆弱，因为模型更难同时拟合毒化点与干净点。
- 优化算法与损失函数（第 6.3 节、图 11）：防御者改用单遍随机梯度下降或 logistic 损失时，除 loss 防御外三种攻击仍然有效，loss 防御显著降低了攻击造成的损害。
- 标签翻转对照（附录 D、图 13）：改编自 Xiao 等人的 alfa 攻击在 Enron 上只把测试错误率提高约 2%，而本文攻击在同一数据集上提高 15% 到 20%；论文的结论是仅修改标签而不修改特征不足以构成高杠杆攻击。
- 附录 C 的对照（图 12）：影响攻击在 Dogfish 上把测试错误率从 1% 提高到 8%，在 MNIST-1-7 上没有明显效果，而在 Enron 上从 3% 提高到 23%。

## 8. 开销

**攻击生成的开销，论文有报告。** 表 2 给出每种攻击达到 17% Enron 测试错误率所需的时间：影响攻击 18.3% 的测试错误率对应 17,000 秒，KKT 攻击 22.5% 对应 27 秒，min-max 攻击 23.7% 对应 1,700 秒。第 5.3 节补充了硬件条件：每种攻击在 Intel Xeon E5 处理器的 2 个核心上运行，影响攻击另外使用了 GeForce GTX Titan X 做 GPU 计算；影响攻击的主要瓶颈是公式 (10) 中的逆 Hessian 向量积，而 KKT 与 min-max 求解的是凸子问题，可用通用凸优化求解器。诱饵参数的候选数量也有报告：Enron 扫描 r ∈ {1, 2, 3, 5, 8, 12, 18, 25, 33} 与损失分位数 q ∈ {0.05, 0.10, …, 0.55}，得到 99 个候选，剪枝后剩 48 个；IMDB 取 r ∈ {1, 2, 3, 4, 5} 与 q ∈ {0.1, 0.2, …, 0.6}，剪枝后剩 18 个（附录 B.2）。min-max 攻击在全部实验中使用固定的 loss 防御阈值 τ = 0.25（附录 B.3）。

**防御侧的开销：论文未报告。** 论文没有给出数据清洗防御本身的时间、内存或额外训练成本。第 8 节只在讨论更强的防御方向时笼统指出，在多个数据子集上训练多个模型的方法会带来额外计算成本。

**通信与存储开销：论文未报告。** 论文是集中式设定，没有讨论通信量、上传下载带宽或存储占用。

## 9. 假设、局限与自适应攻击

**方法成立所依赖的假设。**

- 攻击者知道测试集 Dtest、干净训练集 Dc 以及防御者的训练流程（第 2.1 节）。论文自己说明，现实中攻击者未必拥有全部这些信息，但为了“安全设计”原则，防御应当对拥有这些信息的攻击者也稳健。
- 实验中的假设模型是线性分类器 fθ(x) = sign(θᵀx)（第 2.1 节）。
- 攻击者与防御者都能求出使训练损失全局最小的参数（第 8 节明确把这一点列为攻击的局限，并说明这对凸损失是合理假设）。
- 定理 1 要求每一类的可行集 Fy 是凸集，并要求损失是形如 ℓ(θ; x, y) = c(−yθᵀx) 的间隔型损失，其中 c 凸、单调递增、二阶可导且 c″/c′ 单调不增；L2、slab、loss、SVD 四种防御在论文的设定下都满足凸性条件，k-NN 防御不满足但被集中化规避（第 3.1 节、Remark 2）。
- 攻击者注入的比例很小，论文只考虑 3% 或更低（第 1 节）。
- min-max 攻击额外假设测试数据与干净训练数据同分布，即只适用于无目标设定（第 2 节、第 4.3 节）。
- 攻击者事先知道防御者的正则化系数 λ，论文承认这对防御者不利（第 5.2 节脚注 2）。
- 攻击者能观察到干净训练集 Dc；论文在第 6.1 节的脚注 4 中推测，如果只有同分布的另一个数据集 D′c，由于攻击主要通过 Dc 上的平均梯度依赖它，替换应当影响不大，但论文没有为此做实验。
- 防御者按类别剔除固定比例的点（实验中 p = 5%），并且可行集的拟合可以近似固定在干净数据上（第 3.2 节的第二条近似）。

**论文自述的局限。**

- 影响攻击直接但缓慢，对基于模型的防御（如 loss 防御）效果较差，迁移性也较差（表 2、第 8 节）。
- KKT 攻击依赖诱饵参数这一启发式，论文明确指出“在更复杂的防御下这一启发式可能失败”（第 8 节）。
- min-max 攻击同样依赖诱饵参数，比 KKT 慢，且只适用于无目标设定（表 2）。
- 攻击依赖凸性，论文把非凸模型（尤其是神经网络）列为未解决的问题：在非凸设定下，针对某个随机种子有效的投毒攻击换一个随机种子可能失败，单个毒化点也可能让防御者卡在很差的局部极小值（第 8 节）。
- 攻击不是干净标签攻击，毒化点在人类专家看来不一定标注正确（第 7.1 节）。
- 论文预期“更复杂的数据清洗防御可能击败本文的攻击”（第 8 节），也就是说本文攻击只对它所建模的那五类检测器有效。
- 在高 ϵ 设定下，本文影响攻击明显弱于 Steinhardt 等人的半定规划方法，论文把原因归为步长调参、初始化或梯度下降在高 ϵ 下的适用性，并声明这不是本文重点（第 5.4 节脚注 3）。

**是否评估了自适应攻击者。** 论文的攻击本身就是**针对防御做过优化的攻击者**：第 5.2 节明确写“我们针对所有防御分别优化了每一个攻击”，第 3.2 节与第 4.2.2 节、第 4.3.2 节把防御的可行集直接写进攻击的约束，算法 1 还会反复用新的毒化点重新拟合异常检测器。因此从“攻击者知道防御并据此优化”的意义上说，本文评估的是自适应攻击，其结果是五种清洗防御全部被绕过。**分析：** 但论文没有评估反向的自适应闭环，即防御者在知道攻击形式之后调整阈值、更换检测器或改变训练流程后攻击是否仍然有效；第 6 节评估的是攻击者对测试集、正则化、优化器和损失函数的信息缺失，而不是防御者对攻击的适应。

**论文未说明的部分。** 论文没有讨论联邦学习、客户端抽样、聚合规则、隐私保护、大语言模型、参数高效微调或 LoRA 增量的任何内容。

**迁移到联邦 LoRA 微调时可能失效的假设（以下均为分析）。**

第一，凸性与间隔型损失不成立。定理 1、KKT 条件与 min-max 的鞍点推导都建立在“每类可行集是凸集、损失是 c(−yθᵀx) 形式的凸函数、防御者取全局最优”之上；LoRA 微调大模型时损失是自回归交叉熵，参数只覆盖低秩增量，模型整体非凸，论文第 8 节自己就把这一情形列为未解决的问题，因此 2 个点即可实现任意攻击这一结论不能直接搬用。

第二，样本的表示形式不同。论文的样本是定长数值向量，整数输入用线性规划松弛加随机舍入处理；LoRA 微调的数据是变长 token 序列，论文未说明如何把舍入与投影推广到离散序列。

第三，“类别”这一概念不同。论文的每一种防御都以类别质心、类间连线或按类剔除比例为基础，而指令微调或偏好对齐的数据通常没有二分类或多分类标签，类质心这一视图在联邦 LoRA 场景下需要重新定义。

第四，数据可见性发生根本变化。论文的五种防御都要求防御者能看到全部训练样本的原始特征，SVD 与 k-NN 还要求跨样本或跨客户端的全局视图；在标准联邦 LoRA 中服务器通常只能看到各客户端上传的适配器增量，因此若只在服务器钩子上实现插件，这五种防御大多无法落地，只有 loss 防御可以用“全局模型在客户端样本上的损失”做一个弱化版本。

第五，攻击预算的语义变化。论文的 ϵ 是毒化样本占单一集中训练集的比例，而在联邦场景下等价物可能是恶意客户端样本量占全局样本量的比例，也可能是恶意客户端数占参与客户端数的比例，两者对攻击效果的影响不同；论文未说明。

第六，论文的攻击者能看到全部干净训练数据并知道防御者的训练流程与正则化强度，在联邦 LoRA 中单个客户端通常看不到其他客户端的数据，这是对攻击者更弱的假设；反过来，如果恶意方是服务器或聚合器，则能同时看到多轮增量，这种能力组合论文完全没有建模。

## 10. 对防护库设计的含义

以下五条全部为**分析**。

第一，采集底座需要在“样本入池”这一信任边界上提供逐样本的原始视图。论文的攻击入口是训练数据准备阶段，而它要绕过的五种防御全部需要逐样本的特征与标签（类质心、投影方向、逐样本损失、低秩残差、近邻距离都从这一层导出）。在联邦 LoRA 库中，这对应客户端本地数据装载前后的钩子，需要记录特征或文本本身、标签、来源标识与轮次，并允许插件读取而非仅读取聚合后的更新。这是通用需求，不针对本论文。

第二，插件接口应当把“只需要全局统计量的防御”和“需要原始样本矩阵的防御”明确分成两类。L2 与 slab 只依赖每一类的均值，可以用服务器端的聚合统计量支持，通信代价极小；loss 防御需要一个在未清洗数据上训练出来的参考模型，以及该模型在每个样本上的损失；SVD 与 k-NN 需要全量样本矩阵或样本两两距离。这三类的数据可得性在联邦下差别很大，库如果只提供统一的一种数据视图，就会迫使插件要么拿不到数据、要么越权访问原始样本。这一分类是这篇论文特有的直接后果。

第三，库需要跨轮状态与参考模型能力。论文的算法 1 在“固定异常检测器求解毒化点”与“用新毒化点重新拟合异常检测器”之间交替，第 5.4 节显示迭代版本比固定版本略好；KKT 与 min-max 攻击（以及与之对抗的 loss 防御）都需要先训练一个参考模型或诱饵模型（算法 3）。因此服务器钩子需要能够读取并回写每轮的检测器参数，并允许插件发起一次额外的参考训练或全量前向计算，接口上应把这类插件标注为需要额外计算。

第四，检测插件不应只依赖论文所建模的那五种异常分数。论文用受控实验说明，距离类、损失类、低秩类与近邻类检测器都可以被一个协调过的攻击者同时绕过；相对更难绕过的信号是攻击的“集中性”本身，即大量毒化点落在极少数近似重复的位置上（定理 1、第 3.1 节）。库的采集底座因此应当在客户端上传前记录批次内的近邻密度与近似重复度，并在服务器侧保留跨客户端、跨轮次的聚类视图；论文同时指出攻击者可以加噪声来破坏这种集中性，所以这一信号只能作为其中一路证据。这是分析，论文没有给出任何可用的检测算法。

第五，库应当显式区分“客户端钩子”与“服务器钩子”上可实现的防御。论文全部实验都在一个能同时看到清洗与训练的数据持有方内部完成，防御者既做检测又做训练；若库只暴露服务器钩子，则本论文的五种防御中只有 loss 防御的一个弱化版本可能实现，其余需要新增客户端钩子或引入可信数据平面。这一约束是通用的架构问题，但本论文把它暴露得最直接：一个把全部原始数据视为服务器可见的防护库，在联邦 LoRA 下会整体失效。

第六，干预接口需要支持“在训练前按阈值剔除样本并重新训练”这一最基本的动作，并允许把域约束（论文中的非负整数与 [0, 1] 区间）一并写进过滤条件。论文中防御者的全部干预就是在训练前剔除样本再训练；在联邦 LoRA 库中，这对应客户端训练前的样本级过滤返回值，以及服务器侧的重新加权或重新采样钩子。这是通用需求，只是本论文的可行集形式给出了一个具体的过滤规则模板。

## 11. 原文依据

1. 摘要：“Our attacks are based on two ideas: (i) we coordinate our attacks to place poisoned points near one another, and (ii) we formulate each attack as a constrained optimization problem”——支撑第 3 节与第 4 节关于攻击入口与两条核心思想的论断。
