## 3. 引用规范

1. 报告中每个事实性陈述标注 `[key, §节/页码/表号]`，key 与 `references.bib` 一致。
2. 区分三种陈述：**原文报告**（论文给出的结果）、**我们的分析**（推导、对比、判断）、**待验证设想**（尚无实验）。
3. 论文数值只引用表格值；正文与表格冲突时两者都记录，不擅自取舍。
4. 图像/传统 FL 的实验结果不得写成 LLM 或 LoRA 的证据；迁移结论必须标为“我们的分析”或“待验证”。
5. 版本固定：arXiv 论文记录版本号与日期；会议版本与 arXiv 版本不同时注明。

## 5. 迁移可行性分析框架（用于 RQ3）

对每个图像侧方法逐项回答，结论分为 **直接可迁移 / 改造后可迁移 / 原理失效 / 需实验判定**：

| 维度 | 需要回答的问题 |
|---|---|
| A 攻击目标 | 图像侧目标（非定向降精度、后门）在 LLM 中对应什么（安全对齐退化、触发后门、定向错误）？危害判定方式是否可比？ |
| B 数据空间 | 连续像素空间的“近分布扰动/生成样本”在离散 token 空间怎样实现？语义可读性是否使数据侧检测变得平凡？ |
| C 参数空间 | 全参数 CNN 更新 → LoRA 低秩更新：维度、非唯一参数化（BA=(BQ)(Q⁻¹A)）、A/B 聚合方式是否破坏距离/分布度量？ |
| D 训练动态 | 从头训练的小 CNN → 预训练大模型少步微调：更新幅度、跨轮漂移、良性异质性的量级是否使横向/纵向检测仍可分？ |
| E 信任与可见性 | 方法需要服务器看到什么（明文更新、客户端自报数据描述、测试集）？与安全聚合、恶意客户端伪造是否冲突？ |
| F 规模与成本 | 逐样本/逐客户端计算在 LLM 规模下的时间、显存、通信开销；能否用投影、末层、低秩代数近似？ |
| G 评测 | 需要哪些数据集、判定器、基线，才能在 LLM 场景检验该原理？ |
