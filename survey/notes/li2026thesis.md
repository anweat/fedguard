## 2. 方法原理

### 2.1 MoEGAN（第 3 章）
- 问题：单一 GAN 输出同质化 → 局部更新跨轮一致 → 被 PCA/MCD 类方法捕获（p.35，图 3-2）。
- 生成器：噪声与标签嵌入逐元素相乘 `z = ε ⊙ Emb(y)` → MoELatent（E 个 `Linear+ReLU` 专家，门控 `Softmax(W_g z)` 加权求和）→ 转置卷积上采样至 3×32×32（p.36–37，表 3-2，式 3-2）。
- 判别器：ACGAN 式双分支（真伪 + 11 类辅助分类）（表 3-3，p.38）；损失 `L_adv + λ·L_aux`（式 3-3，p.41）。
- **中毒方式**：用训练好的生成器以**随机标签** y_random 生成逼真样本，替换本地数据（算法 3-1 第 9–10 行，p.39–40）。即“逼真图像 + 错乱标签”的非定向投毒。
- 理论论述：MoE 使生成分布近似多峰混合 `P_G(x|c) = Σ P(E_i|z) P_G(x|c,E_i(z))`（式 3-4，p.41），属定性论证。
- 实验：Fashion-MNIST、CIFAR-10、RTFD（铁轨缺陷，883 训练/116 测试，ResNet-18 冻结前 8 层）（p.42）。

### 2.2 SMA（第 4 章）
- 大女巫把真实数据切成 v 个不相交子集分给小女巫；每个小女巫只训练 MoE 的一个专家并生成专属中毒集；大女巫回收专家，**门控权重与偏置置零做等权融合**，生成自身中毒集（算法 4-1，p.62）。
- 目标：小女巫之间更新余弦相似度低于检测阈值 τ_detect，从而规避 FoolsGold 类相似度防御（式 4-4，p.61）。
- 部署分析：跨设备场景准入弱、易实施；跨孤岛场景需窃取证书，门槛高；采用“一次离线生成、持续投毒”规避每轮算力开销（p.63–64）。

## 4. 防御思路（**论文未做实验验证**）

1. **决策一致性防御（针对 MoEGAN）**：服务器用少量干净验证集，把每个客户端更新叠加到上一轮全局模型上，度量 ① 预测分布 KL 偏移、② 分类间隔变化、③ 混淆矩阵 Frobenius 差异，加权得分后硬截断 + 按分数倒数加权聚合（式 3-10~3-13，p.53–54）。
2. **可信锚点偏离度 + 相似度关联图（针对 SMA）**：少量经物理身份认证的可信客户端均值作参考梯度 → 与参考梯度余弦相似度低于 τ_low 的节点作为种子 → 在历史成对相似度图中挖掘与种子相似度高于 τ_high 的同谋并连带惩罚（式 4-6、4-7，p.70–71）。

## 5. 成立条件与局限（我们的分析）

1. 两种防御都**只有设计没有实验**，引用时只能称“提出的防御思路”。
2. 决策一致性防御假设服务器持有覆盖主任务的干净验证集，与 FLTrust/MCD 的服务器数据假设同类；在 LLM 场景可对应“服务器端行为探针集”。
3. 可信锚点假设存在经认证的良性客户端，并以其平均更新方向为“正确方向”；在强 non-IID 下锚点方向可能与正常少数领域客户端正交，存在误伤风险。
4. 关联图连带惩罚依赖“同谋内部高相似”；而 SMA 自身设计正是降低小女巫之间相似度，图 4-9 中高相似只出现在大女巫之间，因此种子扩散能否捕获小女巫需要实验。
5. 第 3.6 节首句称 MoEGAN“使恶意客户端在参数空间中保持高度的分布一致性”，与第 3 章“打破一致性”的主张表述相反，推测是“与良性分布一致”之意，引用时需避免照抄。
6. 实验中 SMA 隐蔽性评估设 N=10、全体参与，与攻击性实验的 N=60/K=10 设置不同。

## 6. 与本项目的关系

| 原理 | 迁移方向 |
|---|---|
| 生成器多样性 ↔ 更新一致性 | 文本侧对应“生成投毒数据的模板/风格/改写多样性”，可设计单模板 vs 多专家（多提示词/多生成模型）投毒对照，检验 ΔLoRA 跨轮一致性信号 |
| 女巫分拆与去相似化 | 对应联邦 LLM 中一个攻击者注册多个客户端、分别承担不同有害主题或不同触发子任务；检验 FoolsGold/余弦类检测在 LoRA 更新上的失效 |
| 决策一致性（输出空间） | 对应服务器端对每个客户端 adapter 的行为探针（安全问答拒答率、困惑度、输出分布 KL），与 FedLLM-Attack 的评测与 Safe-FedLLM 的参数探针形成对照 |
| 可信锚点 + 关联图 | 对应 FLTrust 式根数据/可信客户端 + 客户端相似度图；需在自然 non-IID（FedLLM-Bench）下测试误伤 |
