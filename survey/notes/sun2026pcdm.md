# PCDM: A Diffusion-Based Data Poisoning Attack Against Federated Learning Systems

## 1. 攻击模型（§III-B, p.3–4）
- 目标：非定向降精度 + 规避服务器检测。
- 能力：控制一个或多个客户端；**只能改本地数据集，不能影响本地训练过程（黑盒数据投毒）**；不与外部实体协作。
- 与学位论文第 3 章威胁模型相比，明确收紧为“纯数据投毒者”，与 FedLLM-Attack/Safe-FedLLM 的隐含假设一致（我们的比对）。

## 2. 方法（§IV, pp.4–9）
- 在条件 DDPM 的全局上下文中注入**投毒向量 v**：`o(x_{t−1}, v) = Conv(x_{t−1} + r(v))`（Eq.10），生成特征 `x_poison = x_t + σ_v·v + μ_v`（Eq.11）；σ_v、μ_v 控制投毒强度与方向，对应攻击性-隐蔽性旋钮（Eq.12）。
- 性质分析：v 不改变前向扩散过程（Property 1）等，并给出攻击性能的理论保证（§IV-B，待读）。
- “跳跃扩散”（jumping diffusion）降低生成开销，延续 LSDAM 的“大步”思想。
- 联邦执行：训练前生成中毒集替换本地数据，之后每轮用其训练（Eq.41–42，p.9）。

## 3. 实验设置（§V-A, pp.9–10）
- 100 客户端、每轮 20%、200 轮、本地 5 epoch、batch 128；IID 与 Dirichlet α=0.5 non-IID。
- MNIST、Fashion-MNIST、CIFAR-10、CIFAR-100、无线场景 VRAI；11 种防御（含先进拜占庭鲁棒聚合），7 种攻击基线（标签翻转、PoisonGAN、三类噪声、VagueGAN 等）。
- 所有方法共用相同划分索引与随机种子。

## 5. 成立条件与局限（我们的分析）
1. **效应量小**：多数设置下精度下降在 0.3–2.5 个百分点；只有 CIFAR-100、30% 恶意时达到约 8 个百分点。与 LLM 安全攻击（MD-Judge 下降 40–60 个百分点，`ye2024emerging`）的量级完全不同，说明两个领域“隐蔽性—效果”权衡所处的区间不同。
2. 非定向降精度这一目标在 LLM 指令微调中没有直接对应物；迁移时要把“投毒强度旋钮”映射到安全退化或后门强度。
3. 连续像素空间中的加性投毒向量无法直接用于离散 token；文本侧对应物是在嵌入空间或生成提示词层面控制“偏离度”。

## 6. 与本项目的关系
- 课题组攻击谱系的最新节点：VagueGAN（一致性异常）→ LSDAM（多样性破解）→ **PCDM（可控投毒向量 + 轻量扩散）**。
- 研究启示：**“可控强度 + 高多样性”的隐蔽投毒生成器**是检验 LLM 侧防御鲁棒性的必要压力测试；文本侧可对应“多模板/多生成模型 + 有害程度可调”的投毒数据生成。
- 论文结论写明未来工作是研究对此类生成式隐蔽攻击的对策，与本项目“迁移防御”方向衔接。
