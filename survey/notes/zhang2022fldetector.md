# FLDetector: Defending Federated Learning Against Model Poisoning Attacks via Detecting Malicious Clients

- Key：`zhang2022fldetector`；KDD 2022；arXiv:2207.09209
- 作者：Zaixi Zhang, Xiaoyu Cao, Jinyuan Jia, Neil Zhenqiang Gong
- 类别：C3（服务器侧、跨轮历史检测）
- 阅读深度：方法（§3–§4）+ 实验设置；实验结果表待补读

## 1. 威胁模型（§3, p.3）
- 攻击者控制 m 个恶意客户端（伪造或被攻陷），**直接上传构造的模型更新**（模型投毒，g ≠ ∇f），知道本地数据、损失与学习率。
- 服务器不可攻陷；目标是尽早检出多数恶意客户端，移除后重启训练，交由拜占庭鲁棒聚合处理剩余少数。
- 形式化简化：每轮客户端做一步梯度下降并上传梯度；实验中**所有客户端每轮都参与**（§5 设置，p.6）。

## 2. 方法（§4, pp.3–4）
- 对良性客户端，由中值定理 `g_i^t = g_i^{t−1} + H_i^t (w^t − w^{t−1})`（Eq.2）。
- 用过去 N 轮全局模型差 ΔW 与全局更新差 ΔG，以 L-BFGS 估计**所有客户端共用**的 Hessian 向量积 Ĥ^t，预测 `ĝ_i^t = g_i^{t−1} + Ĥ^t(w^t − w^{t−1})`（Eq.3）。
- 可疑分数：预测与实际更新欧氏距离，按 L1 归一化后取窗口 N 内平均。
- 检测：Gap statistic 判断是否可分为多簇；若可分，k-means 分两簇，均值较高者为恶意；一旦检出即移除并重启。
- 另设计了针对 FLDetector 的自适应攻击（在攻击目标中加入一致性约束，权重 λ）。

## 3. 实验设置（§5, pp.5–6）
- MNIST、CIFAR10（100 客户端，non-IID 度 0.5）、FEMNIST；默认 28% 恶意客户端，每轮都攻击。
- 攻击：Untargeted Model Poisoning、Scaling、DBA、ALIE 等；指标 DACC、FPR、FNR。

## 4. 与 MCD 的关键对照（我们的分析）

| 维度 | MCD（`sun2024thesis`） | FLDetector |
|---|---|---|
| 异常方向 | 恶意客户端跨轮**过度一致**（覆盖指标偏小） | 恶意客户端跨轮**不一致**（与预测偏差大） |
| 攻击类型 | 数据投毒（生成式中毒数据） | 模型投毒（构造更新） |
| 参照 | 可信基准客户端（服务器自训模型） | 全局模型的曲率近似，无需干净数据 |
| 参与假设 | 允许未被采样轮为 NULL | 实验中每轮全体参与；部分参与需补全历史 |

两者说明“纵向历史”信号在不同攻击下符号相反：**一致性本身不是恶意的标志，偏离“良性训练动态”才是**。迁移到 LLM LoRA 时，应把跨轮检测定义为“相对良性动态模型的双侧偏离”，而不是单侧阈值。

## 5. 迁移到 LoRA 联邦微调的问题
1. 多步本地 AdamW + LoRA 下，Eq.2 的一阶近似与共用 Hessian 假设不再成立，需要实验验证预测误差是否仍能区分良性与恶意。
2. 数据投毒客户端（FedLLM-Attack）按正常训练代码生成更新，其跨轮动态可能与良性一致，FLDetector 的前提（g≠∇f）不满足。
3. 部分参与（每轮 3/10）导致单客户端历史稀疏。
4. L-BFGS 在 LoRA 参数维度（数百万）上可行，但需确认 A/B 参数化下的曲率估计意义。
